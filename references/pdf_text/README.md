## 2. 行号 / 页码引用约定（重要）

- **`L*.txt`**：页边界由 `========== PAGE N ==========` 标记，引用写作"讲义 L3 P40–P42"。
- **`S*.txt`**：**内容逐字未改、行数未变**，因此"`S2.txt` 第 2972 行"**等于**"原始字幕 `2.txt` 第 2972 行"。
  所有笔记、`decide.md`、`playbook.md` 里对字幕的行号引用**永久有效**，可直接回本目录核对。
- 引用格式统一为 `S<文件>:<行号>` 或 `S<文件>:<起>–<止>`，例如 `S2.txt:2972–3019`。

## 3. PDF 序号 ≠ 字幕"第 N 天"（错位表）

讲义是**按主题切分的 5 个 deck，不是按天录的**；字幕才是按天录的。两者**多对多**，不要按编号硬对。

| 讲义 | 实际主题 | 对应字幕 |
|---|---|---|
| `L1`（83p） | AIMD 基本原理 + VASP 做 AIMD + 后处理 | `S1.1` `S1.2`（第 1 天）+ `S2` 前段（后处理实操） |
| `L2`（69p） | CP2K 简介 / 编译 / 建模 | `S2` 后段（第 2 天） |
| `L3`（156p） | CP2K 计算流程 + 参数全集 | `S3`（第 3 天）为主 + `S4` 部分（基组赝势/优化/NEB/频率/AIMD/DFT+U） |
| `L4`（64p） | TRAVIS + 电子结构分析 | `S5` 前段（第 5 天） |
| `L5`（53p） | 自由能势能面三法 | `S5` 后段（第 5 天） |
| （无对应讲义） | NEB / 频率 / Au20 / QM-MM | `S4`（第 4 天）—— **PDF 里没有这些内容** |

> 详细到"页 ↔ 行"的对应见 `MAPPING.md`。
> 课程大纲原始出处：`L1.txt` **P2**（9/26–9/30 五天安排）。实际讲课进度比大纲**慢半拍**：
> 第 2 天补完了大纲第 1 天的后处理，第 3 天才讲大纲第 2 天的"参数详解"，第 4 天讲大纲第 3 天的
> 过渡态 + 第 4 天的频率/DFT+U，第 5 天与大纲一致。这是理解错位表的关键。

## 4. 字幕同音错字对照（快速参考）

字幕是语音转文字，含大量同音错字。**完整表见 `references/course_survey.md` §3**。高频几例：
`cp two k`=CP2K、`VSP/VSGO`=VASP、`AAMD`=AIMD、`验室/验尸`=赝势、`机组`=基组、`京弯/金毛/精包`=晶胞、
`军方位1`=MSD、`BSS 1`=BSSE、`镜像分布函数`=RDF、`二氧化石`=TiO₂、`进二`=Au20、`PM,F`=PMF、
`METDYNAMICS`=metadynamics、`伽马点/钢板点`=Γ 点、`扩高`=扩胞、`风`=峰、`差/差点`=插点、`飞艇`=fitting。

## 5. 溯源维持约定

- 改 `course_learned.md` / `course_notes.md` / `decide.md` 时，若涉及具体表述，**回对应 `learn_Ln.md` / `Ln.txt` / `Sn.txt` 核对**，不要凭记忆改。
- **字幕原文与讲义抽取文本一律不改**（即使发现其中是错的）——保留真相溯源；
  对讲师的错误、口误或与官方冲突处，只在综合稿标注更正（例：PPT 原写 MSD"先平均再平方"，
  讲师当场更正为"先平方再平均"，原始稿保持原样，更正写在 `course_notes.md A2`）。
- 若发现 `learn_L*.md` 本身有误（如 `learn_L4.md` 曾判定"BSSE 不存在/无法溯源"，实为搜错文件），
  同样**不修正原始稿**，只在综合稿与 `decide.md` 标注更正并给出正确出处。
- 本目录文件**不会被 SKILL.md 自动加载**，仅在需要时手动 Read。

### 6.2 引用约定与边界

- 引用写作 `videonotes/<笔记名> L<行号> [mm:ss–mm:ss]`。
- **两者冲突时**：讲义写了的以 `L*.txt` 原文为准；只有录屏里才有的操作细节
  （某个脚本的实际输出、某个界面选项）以 `videonotes/` 为准。
- **两者都晚于录屏、都可能读错**。能回 `L*.txt`/`S*.txt` 核对的，一律回原文核对。
- `videonotes/` 的 6 份笔记**从源归档逐字节复制、只读不改**。
  其 15 张录屏配图（约 4 MB）**未随笔记复制**（理由与清单见
  `videonotes/README.md` §2），因此笔记正文里的 `![](img/…)` 相对链接在本仓库内不可解析。
