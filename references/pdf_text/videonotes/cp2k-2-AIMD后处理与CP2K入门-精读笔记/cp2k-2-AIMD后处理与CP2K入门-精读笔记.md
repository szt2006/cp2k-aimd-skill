### 2.2 ⚠️ 边界穿越导致的"跳跃"问题 [08:37–09:41]

### 2.3 ⭐ 应用实例：氮气活化（配合物催化）[11:36–13:22]

**反应背景**：一个**配合物**活化氮气分子，有**两种方式**：

| 方式 | 说明 |
|---|---|
| **解离式**（Dissociative） | 直接解离 |
| **缔合式**（Associative） | 加氢 → **生成 N–N–H 中间体** |

> 🔧 讲师补充：**"如果做电氮化学的同学应该对中间体非常熟悉，这就是氮气在电催化氮化里面第一个步骤就是生成 N–N–H 中间体。"** `[11:57–12:12]`

**AIMD 如何分析这个反应** `[12:12–13:22]`：

- 跟踪的键：**N–N 键长**、**N–H 键长**、**H–O 键长**
- 原因：**氢肯定来自溶液中的质子**，所以要跟踪 N–H 与 H–O
- 目的：观察**氢原子如何通过"质子链传递"（proton relay）转移到配合物的铁中心**

**结果图（右侧）的判读** `[12:42–13:22]`：

- 一开始有一些 H–O 键长较大（**未成键**）
- 约 **800 fs** 处**化学反应发生**，**新的化学键生成** —— H–O 键长从较长范围**变到约 1 Å 左右**，说明氢氧成键
- 同时**旧的化学键断裂**
- ⭐ **结论**：**"只要有化学反应发生，它就是伴随着新的化学键生成和旧的化学键断裂。"**

**第二个类似例子** `[13:22–13:42]`：**胺类分子 + 亚硝酸根**，同样是**质子链传递**，用同样方法跟踪键长。

> 💡 **作图范式**：**横坐标 = 时间，纵坐标 = 键长** → 即可跟踪化学反应的进行情况。

## 4. 后处理③：径向分布函数 RDF [14:39–28:12] ⭐ 本讲最详细的一节

### 4.1 物理意义与定义 [14:43–15:39]

> **RDF 的物理意义**：先把一个粒子当做**参考粒子**，然后计算**相距参考粒子为 R 处的粒子密度**，即算它的**密度分布**。

- **中心参考**可以是：**一个原子**、**一种元素**，或者**几个原子**（算的时候把每个原子都当中心，再求 RDF）`[14:57–15:05]`
- ⭐ **归一化约定**：**"我们定义径向分布函数的时候，就是把无穷远处定义成 1，这样我们看图的时候比较好看。"** `[15:12–15:39]`
  - 因为均匀分布的液体在无穷远处就是 1
  - ⚠️ **真实密度 = 体系的 ρ × RDF** `[15:22]`

### 4.2 ⭐ 从 RDF 能读出什么 [15:39–16:53]

| 特征 | 含义 |
|---|---|
| **第一个峰** | **第一配位原子层** |
| **第二个峰** | **第二配位原子层** |
| **峰的积分面积** | **配位数**（第一峰积分 → 第一配位层原子数） |
| **峰最高点对应的横坐标** | **配位距离**（键长或原子间距） |

⚠️⚠️ **积分配位数的一个大坑** [16:05–16:23]：

> **"这里要注意的一点就是我们在算这个积分峰面积的时候，我们别从 Origin 里面自己去积分，如果在 Origin 里面自己去积分，积分出来这个数值不对的 —— 因为它是个球面积分，这个积分的时候要引入这个 4πR²，是引入这个球面积分的，并不是直接去做这个面积积分。"**

🔧 即：配位数是**对 4πr²g(r)ρ dr 积分**，不是对 g(r) 曲线直接求面积。

### 4.3 VMD 里算 RDF 的完整操作 [17:41–20:30]

**必要前提** ⚠️ [16:53–17:41]：

> **"我们在做 RDF 分析的时候，一定要把这个周期性边界条件给加上。因为如果不加，我们相当于只在这个区域内统计，而相邻镜像里的原子本来也应该算到 RDF 里来（无限重复的）。不加 PBC 求算 RDF 其实是不准确的。"**

**加 PBC 的两种方式** [17:55–19:17]：

| 方式 | 操作 |
|---|---|
| ① **命令行** | 在 VMD 命令行窗口输入 `pbc set {...}` |
| ② **菜单** | 在 **Utilities**（讲师口述为"Lutidities"）里 → **Asset Unit Style Dimension** 直接填 `7.82, 7.821, 7.823` `[19:11]` |

**RDF 计算器设置** [19:21–20:30]：

| 参数 | 设置 | 说明 |
|---|---|---|
| **Selection** | 选**轨迹** | 此处只导入了一条轨迹 |
| **输入方式** | 用 **`name`** 或 **`element`** 都可以 | `name` 代表所选元素 |
| **本例选择** | **氧元素与氢元素** | → 画 O–H 的 RDF |
| ⭐ **横坐标间隔** | **取密一点** | "出来的图精细度会比较高" |
| ⭐ **Integrate** | **勾上** | 会同时输出**积分值** |

### 4.4 ⭐ 水的 RDF 实测结果与解读 [20:30–22:12]

**峰与积分值**：

| 配位层 | 积分值 | 解读 |
|---|---|---|
| **第一配位层** | **正好是 2** | 第一配位层里有**两个氢原子** |
| **第二配位层** | 约 **3.97**（"其实不太到 4"） | 第二配位层"也是有两个氢原子" |
| 第三配位层 | 明显 | |
| 第四、第五层 | **不明显** | |

> 🔧 讲师总结：**"以氧为中心，它能够影响到的氢的结构大概有三层是非常明显的，再往第四层第五层走，就不是那么明显。"**
> 🔧 物理图像：**"正好一个氧，周围一般是围绕着四个氢原子的，其中两个氢原子是另外水分子里面形成的氢键，再往外就是另外水分子里面其他氢的配位作用。"** `[21:49–22:12]`

### 4.5 ⭐⭐ 一个高级判据：配位层之间的"零概率密度" [24:21–26:13]

> 讲师引用**同一篇文章里的两个例子**，指出作者最关心的一点是：**第一配位层与第二配位层之间的那个区域的数值是多少。**

**判据**：

| 情形 | 含义 |
|---|---|
| **第一、二配位层之间概率密度 = 0** | 两层之间**不会发生原子交换** |
| **该区域有概率密度** | 说明**存在交换/迁移** |

**例一：水分子** [24:56–25:33]

- 第一配位层与第二配位层之间**是零概率密度**
- → 说明在模拟过程中，**水分子之间并没有发生氢原子交换**，氢原子不会出现在那个区域
- ⚠️ **反例**：如果模拟**酸性溶液**（其中含有额外的水合质子 **H₃O⁺**），那么**在第一、二配位层之间就会有概率密度存在** `[25:26]`

**例二：Au₂₀ 团簇吸附 CO** [25:33–27:14]

- **Au–C 之间那个位置没有概率密度** → **Au–C 键在模拟中不会断裂**（吸附非常强）
- **Au–Au 之间是有数值的** → **Au–Au 键会发生断裂**
- ⭐ **结论**：**"在这个团簇吸附了一氧化碳分子之后，金原子变成了一个类似于液体的状态，它的 Au–Au 键可以随意地断裂然后再生成……但是 Au–C 键它是比较稳定的。"** `[25:59–26:13]`

### 4.6 ⭐⭐ CO 氧化的反应机理（推翻传统认识）[26:13–27:14]

> 这是本讲**最有价值的一段机理结论**。

**传统催化理论的认为**：

> 一氧化碳分子**自己迁移**到界面处，和界面处的氧气分子反应生成 CO₂。`[26:38–26:45]`

**AIMD 模拟发现的真实情况**：

> ⚠️ **"实际我们做 AIMD 模拟之后发现真实情况不是这样的，并不是一氧化碳自己去跑到界面处和氧气分子反应生成二氧化碳的，而是金原子拉着一氧化碳分子作为一个 Au–CO 这样一个物种一起跑到界面处去发生反应。反应完成了之后，一氧化碳分子会脱附变成二氧化碳脱附，最后这个金原子又会回到这个团簇当中再去吸附更多的一氧化碳分子。"** `[26:45–27:14]`

🔧 **完整链条**：

```
① CO 吸附在 Au 团簇上（Au–C 稳定，Au–Au 类液态）
② 反应发生在界面处（O₂ 吸附在界面处）
③ CO「拉着」一个 Au 原子 → 形成 Au–CO 物种 → 一起迁移到界面
④ 与界面处的 O₂ 反应 → 生成 CO₂ → 脱附
⑤ Au 原子回到团簇 → 继续吸附新的 CO
```

🔧 这与第一部分讲的"**动态单原子催化**"是同一个现象的两种表述（见 §9.4）。

### 4.7 ⚠️ 算 RDF 对晶胞形状的要求：[27:14–28:12]

> **"算径向分布函数的时候，有一点要比较注意：我们最好用正交晶胞。如果不用正交晶胞的话，在 VMD 里是没法添加周期性边界条件的。"**

**问题**：很多材料体系**不是正交的**，例如**石墨烯、MoS₂** 都是**六方形式**（夹角 60°/120°，不是 90°）。

**解决技巧** [27:43–28:12]：

> ⚠️ **"在模拟之前、建模的时候，一定要把它搞成正交的晶胞。"**
> 怎么搞？**需要做晶格矢量旋转** —— **"对原来的晶格矢量乘以一个转换矩阵就可以了。"**
> 讲师说明：**"这个东西我们今天后面会具体的讲怎么去建这样的模型"**（→ 见 §13.3），**"我们在做 AIMD 模拟的时候，尽量都把晶胞做成正交的。"**

## 5. 后处理④：速度自相关函数 VACF → 振动谱 VDOS [28:12–44:02]

### 5.1 VACF 的物理意义 [28:12–29:40]

> **VACF 描述体系当中的粒子，在某一时刻和参考时刻速度之间的关联程度。**

**直观理解**（讲师画了一条轨迹）`[28:12–29:22]`：

- 一个原子在初始时刻速度朝某方向
- 模拟很短时间后，速度变成另一个方向
- 算 **t 时刻速度与 0 时刻速度的点乘**：
  - **点乘越大** → 说明 t 时刻速度与 0 时刻**越平行**
  - **数值越负** → 说明方向**偏得越远**（速度相反时点乘为负）

> **用途**：衡量体系粒子演化过程中，**整体的原子振动和迁移的程度**。

### 5.2 ⭐ 参考点不能只取一个 [29:40–30:42]

> ⚠️ **"算 VACF 的时候，我们这个参考点不能只以一个点作为参考点，我们要以体系当中的每一个点都为参考点。"**

**做法**：以 T0 为参考算后面每一时刻与 T0 的点乘并平均 → 得到"相对于 T0 的 VACF" → **对整个轨迹两两每一个点都算一次点乘，全部平均** → 得到整体的 VACF `[30:30–30:42]`

### 5.3 曲线的解读 [30:42–31:50]

- **横坐标 = 模拟时间**；**零时刻**代表与当前重叠的时刻 → **点乘必为最大值**，讲师**把它标注成 1**（代表最大相关性）`[30:47–31:00]`
- 随模拟时间演化，**相关性降低**；但**不同体系的降低方式不同** `[31:06–31:18]`：

| 体系类型 | VACF 行为 |
|---|---|
| **振动强烈的体系**（如水分子，O–H 振动非常强烈） | 趋于 0 的过程中**发生强烈振荡** `[31:12–31:23]` |
| **某些体系**（如金属熔化） | 原子间振动没那么强，**以比较缓慢的方式趋于 0** `[31:26–31:42]` |

> **无论什么振动方式，VACF 在无穷远处都可以趋于 0。** `[31:42]`

### 5.4 ⭐ VDOS：VACF 做傅里叶变换 [31:50–36:27]

> **对 VACF 做傅里叶变换，可以得到它的振动谱，即 VDOS（vibrational density of states）。**

- 横坐标可转化成**波数**形式 `[32:32]`
- ⚠️ **它可以对应到实验观察到的红外光谱或振动拉曼光谱**，**但 VDOS 并不直接等于红外光谱** `[32:43–32:52]`

> ⚠️ **原因**：**"因为这里面我们在算的时候没有考虑到偶极的信息，红外光谱它是有这个 selection rule，偶极会在里面产生影响。"** `[32:52–33:03]`

**水的 VDOS 实测与对比** [33:03–34:52]：

| 特征 | 位置 | 归属 |
|---|---|---|
| **又大又宽的峰** | **约 3000–3800 cm⁻¹** | 水的**伸缩振动**（**对称伸缩 + 不对称伸缩**），两者都有**偶极变化** → 在红外光谱中反映出来 |
| **又瘦又高的峰** | **约 1500–1600 cm⁻¹** | **剪切振动**（不是伸缩振动） |

🔧 讲师用**静态频率计算对照**说明 VDOS 的优势 `[33:43–34:17]`：

> **用高斯做静态频率计算**得到的振动位置**只是一个单指（单峰），并不能得到振动峰的展宽** —— "这个时候得到的振动峰的宽度是**人为加上**的，是通过**高斯展宽**人为加上的。"
> **但做 AIMD → 算 VACF → 傅里叶变换得到振动 DOS，它的峰的展宽是更为真实的一种情况。**

**单个水分子的静态频率计算** [34:52–35:22]：

- 水分子 3 个原子 → **9 个自由度**
- 减去 3 个平动 + 3 个转动 → **振动自由度 = 3N − 6 = 3**
- 即：**两个振动在 3000 多波数，一个振动在 1600 波数**

⚠️ **AIMD 能做静态计算做不到的事** [35:22–36:00]：

> 实验红外光谱在**1000 波数以下有一个"指纹区"**，这些峰对应到**水溶液当中一些弱的相互作用**（如**氢键相互作用**）所产生的振动峰。
> **"这些振动峰如果我们直接去算一个水团簇的静态计算，把这一部分还原出来是非常困难的。但如果做 AIMD，然后再转化为 VDOS，就可以把它整体的振动模式给它反映出来。"**

**CP2K 的额外优势** [36:05–36:27]：

> 在 CP2K 里**还可以把偶极的信息提取出来**，**"把偶极的信息和速度的信息一块去算它的傅里叶变换，就可以得到真实的红外光谱的数值。"**
> 🔧 讲师预告：**"这个我们最后一天会讲，可以用 `Travis`（转写为"chavas"）那个程序去算。"**

### 6.5 ⭐ MSD 的原理与公式 [52:43–53:28]

> **"其实这个公式很简单，就是考察它在 T 时刻和参考时刻，它的这个位置相距有多远。"**

```
       1   N
MSD = ─── Σ | r_i(t) − r_i(0) |²
       N  i=1
```

- **X₀** = 参考时刻（0 时刻）的位置；**X_T** = T 时刻的位置
- **N 个粒子做加和平均** `[53:04–53:10]`
- **物理意义**：**"在 T 时刻和 0 时刻距离位置差得越远，那就代表着它迁移的也就越远。"** `[53:21–53:28]`

### 6.6 ⚠️ MSD / RMSD 的换算陷阱 [53:28–53:59]

| 量 | 关系 |
|---|---|
| **RMSD** | root mean square displacement **= √MSD** |
| ⚠️ **VMD 的坑** | **"VMD 直接输出来的数据就是这个 RMSD，它不会直接给你输出 MSD，它会输出 RMSD"** `[53:43–53:49]` |
| ✅ **处理办法** | **"我们在处理数据的时候，把这个 RMSD 做一个平方，就可以得到 MSD 了。"** `[53:51–53:59]` |

### 6.7 ⭐⭐ 为什么必须"多参考点平均" [53:59–54:48]

> ⚠️ **"我们不但以第一个时刻 T1 去做 MSD 的计算，最好的方式是多取一些值，比如以 T5、T10 再去算 MSD，把以每一个时刻为参考的 MSD 都算出来之后，再挪在一起做一个平均 —— 这样我们得到的数值就是一个非常平滑的一条曲线。"**

对比：

| 做法 | 结果 |
|---|---|
| **只以一个点为参考** | **"它是一个非常多刺的曲线"** `[54:38–54:42]` |
| **多个参考点平均** | **非常平滑的一条曲线** |

### 6.9 ⭐ 手动多参考点平均的完整流程 [59:55–63:22]

**工作流**：

```
用 VMD 以「第 0 帧」为参考画一次图 → 保存
再以「第 500 帧」为参考画一次   → 保存
再以「第 1000 帧」为参考画一次  → 保存
再以「第 1500 帧」为参考画一次  → 保存
再以「第 2000 帧」为参考画一次  → 保存
        ↓
全部导入 Origin（讲师提供了 Data.opg 文件）
        ↓
⚠️ 对每一列先做平方（因为 VMD 输出的是 RMSD）
        ↓
再把这些线做平均
        ↓
得到平滑的 MSD 曲线 → 拟合直线求斜率
```

**⭐ 讲师主动更正了自己 PPT 里的一个错误** [62:04–62:19]：

> ⚠️ **"这个东西我这个一开始这个 PPT 写的有点问题 —— 一开始在 PPT 里面写的是先平均再做平方，后来有同学提醒我这个地方写的有问题，然后我看一下确实是有问题。大家在自己做的时候要注意一下：这里是先平方，然后再对这些线做平均。"**

🔧 **数学上显然**：`mean(√x) ≠ √(mean(x))`，所以必须**先平方再平均**。

**Origin 里的具体操作** [62:24–63:22]：

1. 把五个参考帧的数据**都复制到同一个表格**里
2. 用 **`Set Column Value`** 写公式，对 **B、C、D、E、F 各列分别做平方**
3. 然后**加起来除以 5**（做平均）
4. 从 **`Fitting`** 菜单做**线性拟合** —— **"Origin 做拟合是非常简单的"**

### 6.10 ⭐⭐ 从 MSD 到扩散系数：Einstein 关系 [63:34–65:46]

> **"算扩散系数的时候，我们是用这个 Einstein 公式去看的。"**

```
       1     d
D = ───── · ── ⟨|r(t) − r(0)|²⟩
     2·d   dt
```

| 项 | 含义 |
|---|---|
| **分子位置** | 用 **MSD 的数值** |
| **除以时间** | → 即 **MSD 的斜率**（"这个位置是代表它斜率"）`[63:47–64:17]` |
| **分母的 d** | **维度** |

⚠️⚠️ **按维度取分母（最易错的地方）** [64:17–64:56]：

| 迁移维度 | 系数 |
|---|---|
| **三维迁移** | **乘以 1/6**（2 × 3 = 6） |
| **二维迁移** | **乘以 1/4** |

> 🔧 讲师的二维例子：**"在石墨烯的双层石墨烯的夹层里面去算它的粒子迁移，这个时候我们就是模拟那个二维的迁移，这个时候我们就是乘以 1/4。"**
> 🔧 本讲的 **Li₄SiO₄ 体系是三维迁移 → 乘以 1/6**。

**单位换算** ⚠️ [65:07–65:46]：

| 场合 | 常用单位 |
|---|---|
| **实验** | **cm²/s** |
| **计算** | **Å²/ps**（"算出来的这个单位一般都是 Å 的平方除以我们模拟时间，比如皮秒、飞秒"） |

> **"在这个单位转化的时候这里就注意一下就可以了。"**

### 6.11 ⭐⭐ 从扩散系数到迁移能垒：Arrhenius 拟合 [65:46–67:38]

> **"迁移能垒的拟合是用 Arrhenius 公式去拟合的。"**

```
D = D₀ · exp( −Eₐ / k_B T )
```

| 项 | 含义 | 怎么求 |
|---|---|---|
| **D₀** | **指前因子** | 直线与纵坐标的**截距** |
| **−Eₐ/k_B** | 斜率相关 | 直线**斜率** |
| **D** | 扩散系数 | 已由 MSD 斜率算出 |
| **T** | 温度 | 模拟温度 |

**操作** [66:20–66:40]：

> ⚠️ **"我们可以去把这个 Arrhenius 公式左右都取一个 log，左右都取一个 log 之后，我们就可以去拟合一条直线。"**
> - 直线与纵坐标的**截距** → **指前因子**
> - 拟合出来的**斜率** → **迁移能垒**

**⭐⭐ 一个重要的方法论对比（本讲亮点）** [66:48–67:38]：

> **用 NEB 也可以算能垒**，但：
> ⚠️ **"用 NEB 去算的时候，你把这个指前因子算得非常不准确的，所以说 NEB 去算它的扩散系数是不准确的。"**
> ✅ **"如果用 AIMD 模拟的方法，我们是通过一种相反的途径：先把扩散系数算出来，然后扩散系数算出来之后，我们再通过直线拟合的方式，就可以把这个扩散能垒 Eₐ 给它算出来。"**

🔧 即：

| 方法 | 能得到什么 | 局限 |
|---|---|---|
| **NEB** | 能垒（较准） | **指前因子不准 → 扩散系数不准** |
| **AIMD + MSD** | 扩散系数（直接） | **反推能垒**（需多温度） |

> 🔧 讲师提到 VASPKIT 官方公众号里有算能垒的教程，"最后的时候可以给大家展示一下"。

### 6.12 ⭐ 文献案例：高压超离子态（用 MSD 判据）[70:54–73:08]

**现象背景** [71:05–71:48]：

> 正常条件下，**液态/固态/气态水分子里的 O–H 键能比较强，想断掉比较难**。
> 但**当体系加到一定的压力，会产生一个临界温度 —— 只要超过这个临界温度，水分子里的 O–H 键就可以发生自由的断裂**，氢原子可以在整个高压体系里自由迁移。
> **"科学家给它起了个名字叫超离子态（superionic state）。"**

**体系** [71:48–71:57]：**氦 + 水**（**两个氦原子 + 一个水分子**组成一个晶胞），然后做了**一个很大的超胞**去做模拟。

**MSD 判读** [72:00–73:02]：

| 温度 | MSD 表现 | 含义 |
|---|---|---|
| **1600 K** | 无论**氢、氧还是氦**，MSD **都是一条非常平的线** | 所有原子都在周围振动，**没有发生迁移** |
| **2000 K** | **氦的那条线"飞起来了"**，变成一条有斜率的直线 | **氦原子在 2000 K 下已经可以自由移动** |
| **2300 K** | **不但氦原子，里面的氢原子也可以自由移动了** | **生成超离子态液体** |

> ⭐ **结论：这个体系的临界温度大概在 2000 K 到 2300 K 之间。** `[72:50–72:56]`
> 然后**拟合这几条直线的斜率，就可以算出迁移率** `[72:56–73:02]`

## 10. CP2K 的定位与优缺点 [84:36–117:08] ⭐ 本讲最有判断价值的一节

### 10.1 瑞士军刀 [84:36–85:47]

> **"关于 CP2K，它其实是一个非常全能的程序，有人把 CP2K 比作瑞士军刀，就是它什么都可以干。"**

能做的：**量子化学、分子体系、第一性原理、表面固体体系、分子动力学模拟、蛋白质、金属、大块材料、经典动力学模拟** `[84:43–84:52]`

> ⭐ **但真正的核心**：**"CP2K 真正最核心、最引人的功能还是做第一性原理分子动力学模拟，这是 CP2K 最强的模块。"** `[84:55–85:00]`

⚠️ **免费程序的代价** [85:05–85:36]：

> **"其他的这些功能 CP2K 虽然非常的丰富，但用起来有的时候不是那么好用。因为 CP2K 毕竟是一个免费程序，开发者没有那么太大的动力把这个功能开发得非常的完善、把手册写得非常的详细。"**
> ⚠️ **"CP2K 有些功能根本连手册都没有，只有开发者自己会用，别人没有人会用。CP2K 有好多这种的功能。"**

🔧 讲师提到**维基百科上对比了上百种计算程序，CP2K 是最全面的一个**，包括 **GPU 加速**也可以做 `[85:36–85:47]`

### 10.2 ⭐ 优势的前提条件：只在"大体系"体现 [85:47–86:19]

> ⚠️ **"CP2K 的优势是算得比较快，但这个算得快呢，是有一点前提 —— 就是只有它在原子数比较多的时候，它的速度快才能显示出来。"**

| 体系规模 | 对比 |
|---|---|
| **不到 100 个原子** | ⚠️ **"用 VASP 去算，速度差不多，甚至用 VASP 去算速度比 CP2K 还要更快 —— 这个时候我们用 CP2K 的意义就没有了"** |
| **至少一两百个原子以上** | ✅ **"CP2K 的优势就会非常的明显"** |

### 10.3 CP2K 更新快 vs VASP 更新慢 [86:19–87:18]

> **"CP2K 它是最快的因素就是它的这个高斯基组和平面波基组混合的代码形式，而且它的代码比较新，大概 2000 年左右之后才开始开发的，而且它采用了很多的'黑科技'—— 有一些比较新的算法都会很快地在 CP2K 给更新出来。"**

对比 VASP：

| 程序 | 更新节奏 |
|---|---|
| **VASP（商业程序）** | ⚠️ **"更新是非常慢的"** —— 5.4.4 是三四年前的版本，直到前几个月才更新到 **6.1**；**"5.4.4 的版本和它 6.1.0 这个版本其实没有什么本质的差别，就是只是增加了很小的几个新功能"** `[86:49–87:10]` |
| ⭐ **CP2K** | **"功能的更新是非常快的，基本不到一年它就可能会更新一个新的版本，这个时候有好多新出的算法都会在 CP2K 里面更新得很快。"** `[87:10–87:18]` |

### 10.4 ⭐⭐ CP2K 的四个缺点 [110:55–116:26]

> 讲师原话：**"CP2K 的优缺点一定要清楚……并不是 CP2K 它各个方面都是完全有优势、完全超越 VASP 那个程序的，这是不太可能的。如果是这样的话，那 VASP 那个程序已经灭绝了。"**

#### 缺点① 算导体比较慢 [110:55–111:48]

| 体系类型 | CP2K 相对 VASP 的速度 |
|---|---|
| **导体**（金属、导电材料） | **"和 VASP 是差不多的"**（在一两百个原子级别上）；原子数变多（四五百个）时 CP2K 仍有优势 |
| ⭐ **半导体 / 有带隙的体系**（氧化铝、氧化硅、氧化碳、氧化铈） | **"CP2K 的速度会甩开 VASP 一大截"** |

> ⚠️ **根因**：**"这主要是因为它这个 OT 算法 —— OT 算法在导体的时候不容易收敛，或者是在导体的时候根本就不能用 OT 算法，导致 CP2K 算导体是比较慢的。"**

#### 缺点② 处理磁性体系比较麻烦 [111:48–112:40]

> ⚠️ **"它和平面波基组的程序不一样 —— 平面波基组程序这个自旋的这个多重度是可以自动地去寻找的"**（给定一个初猜，让它自己寻找最合适的磁态）。
> ⚠️ **"但是 CP2K 这个程序不行，CP2K 这个程序必须让我们提前指定自旋多重度。"**

🔧 类比：**"这个提前指定自旋多重度和我们用高斯那个程序是差不多的"** —— 高斯也要求提前指定**体系的电荷**与**自旋多重度**。
🔧 这一点是 **VASP 的优势**：**"VASP 的话我们不需要指定自旋多重度，我们只需要指定初始的磁矩，给它一个初猜，让它自己去寻找到最合适的磁态就可以了。"** `[112:26–112:40]`

#### 缺点③ K 点功能不完善 [112:40–114:18] ⭐

> ⚠️ **"CP2K 的 K 点功能是最近几个版本才刚刚加进去的，在 CP2K 7.1 这个版本它甚至还不能做 K 点的对称性。"**

**后果** [112:52–113:25]：

> 晶体有对称性时，K 点会有很多**不可约 K 点**（"由于晶体的对称性会使得这个 K 点有一些对称性相同的 K 点，我们把它叫做不可约的 K 点，我们只需要计算一些不可约的 K 点就可以了"）。
> ⚠️ **"但是在 CP2K 这个程序里面不行 —— CP2K 里面我们可以设置 K 点，但是这个 K 点它不会识别对称性，而增加计算量。"**

**⭐ 应对策略** [113:25–114:18]：

> **"一般来说我们在使用 CP2K 的时候，尽量用 Γ 点去计算，就是只用一个 K 点去计算 —— 所以 CP2K 默认就是用 Γ 点去计算了。"**
> ⚠️ **但仅用一个 Γ 点有一点要求：意味着我们要建模的这个体系需要比较大。**
> - ✅ **"至少要给它这个晶胞边长来个 10 Å 以上，这个时候我们才能用一个 Γ 点去把这个体系描述得还算可以。"**
> - ⚠️ **"如果我们这个晶胞非常小，比如说晶胞的边长只有 5 Å，那这个时候我们再用 Γ 点去算，它这个计算的结果就是非常不准确的。"**
> ✅ **做法**：**"我们经常做的一点就是建模之后，如果我们这个模型太小了，可以适当地给它超胞，扩成 2×2、3×3，用这种稍微大一点的晶胞去跑，这样就可以弥补它 K 点功能不完善的这个缺点。"**

#### 缺点④ BSSE 误差 [114:18–115:30] ⭐

> **BSSE = basis set superposition error（基组重叠误差）**

- **来源**：**"这个是高斯基组带来的 —— 所有使用以原子为中心的基组的程序都会有这个 BSSE 误差，包括高斯那个程序全都是有 BSSE 误差的。"** `[114:24–114:35]`
- ⚠️ **CP2K 里尤其明显**：**"这主要是因为 CP2K 使用到的基组比较小，越小的这个基组误差就会越大。"** `[114:35–114:46]`
- ⭐ **表现**：**"算结合能的时候它都会高估结合能。"**
  - 例：**算一个表面上吸附一个分子的吸附能时，用 VASP 与 CP2K 算出来的吸附能可能会有区别**
  - ⚠️ **"大多数情况下，CP2K 算出来的吸附能都会比 VASP 算出来的吸附能稍微大一点"** `[114:52–115:17]`
- ✅ **平面波基组的程序不存在这种 BSSE 误差** `[115:25–115:30]`

🔧 讲师说明**具体含义与校正方法后面讲参数时再说**；本讲末尾答疑里也提到了做法（见 §14.2）。

### 10.5 ⭐⭐ 方法学结论：扬长避短，一篇文章可以用两个程序 [115:30–117:08]

> ⭐ **"不同的程序有不同的优点，也有不同的缺点，这个时候我们在使用不同的程序的时候，就需要去扬长避短。"**

**推荐搭配** [115:36–116:26]：

| 任务 | 用哪个程序 | 理由 |
|---|---|---|
| **大规模 AIMD 模拟**（拿动态信息） | **CP2K** | **"算 AIMD 的时候，CP2K 这个程序有绝对的优势"** |
| **精确的静态计算**（算能垒、算反应过渡态） | **其他程序（如 VASP）** | |

> ✅ **"那么在一篇文章里面我们选择两个程序，只要这个配合得好，这是没有问题的。我们可以用不同的程序得到每个程序擅长的那些部分的结果，然后再去进行讨论 —— 这样的话我们就可以把一个文章做得比较漂亮。"**

⚠️ **反例** [116:30–117:08]：

> **"如果用一个程序把它完全做下来，比如说用 CP2K 或者用 VASP 把一整套计算完全都做下来，那这个程序的缺点就可以暴露出来了。"**
> 例：**"VASP 在做 AIMD 模拟的时候，它处理的体系不够大、它算的速度比较慢，这个时候我们模拟的时间就可能比较短，信息就不足。"**
> ⭐ **一个可观察到的文献现象**：
> - **"VASP 模拟的 AIMD，经常能看到文章里模拟 5 ps、模拟 10 ps 就开始发文章了 —— 但其实这个时间太短了。"**
> - **"如果用 CP2K 去算的话，我们经常能够看到文章至少模拟个 30 ps 或者 30 ps 以上，因为 CP2K 它的计算速度是有优势的。"**

## 12. CP2K 经典应用案例巡礼 [89:54–100:29]

> 讲师带学员快速浏览 CP2K 的经典文献，**"让大家有一个直观的感受"**。

### 12.1 晶核生长 / 动态单原子催化 [89:54–91:39]

- 文章模拟了**晶核的生长**（"这是一个种子，我们把它叫做晶核生长"）`[90:00–90:04]`
- ⭐ **"通过 AIMD 模拟，我们可以得到一些非常新的信息 —— 这些 AIMD 模拟能够给到的信息，在用静态计算的时候是得不到的。"** `[90:30–90:39]`
- 具体观察：
  - **金与一氧化碳物种怎么在表面上迁移** `[90:39]`
  - **动态单原子是怎么生成的** `[90:43]`

⭐ **动态单原子催化（dynamic single atom catalysis）** [90:46–91:34]：

> **"单原子催化（SAC）现在已经是一个比较成熟的概念了，但是这个单原子呢它不但可以本身存在，它也可以在催化反应过程当中动态地生成。"**
> **"其实在做这个 AIMD 模拟的时候我们就发现，这个一氧化碳分子可以把这个金原子给拉出来，拉出来之后把它拉到表面上形成一个孤立的一个金–一氧化碳物种。"**
> **"然后这个孤立的物种呢，参与化学反应的能力会更强，也就是更容易发生反应。"**
> **"所以说我们就把这种在催化反应过程当中动态生成的这种现象叫做动态单原子催化。"**

🔧 这与 §4.6 讲的 CO 氧化机理是**同一现象**。

### 12.2 氧活化 / OH 中间体 [91:39–92:25]

> **"这个模拟这个加氢的过程：这里是一个氧气分子，这个氧气分子在一些水蒸气环境当中，它可以和催化剂表面存在的少许水分子发生一个反应生成 OH 中间体，也就是生成超氧自由基。这个时候氧气分子被活化了，它就可以进一步去参与到后面的催化氧化反应当中 —— 这种反应机理是非常常见的。"**

🔧 讲师列举的应用：

- **ORR 反应**都会有这种 **OH 中间体**
- **NRR 反应（氮气的电催化还原反应）**里面都会涉及到 **NHₓ 中间体**
- **"它的反应机理都是通过一种质子电子传递的过程加氢的这样一个反应。"**

### 12.3 有机反应 + 动态 QM/MM [92:25–93:59] ⭐

> 这是一个**动画模拟**，做的是**有机反应**。**"在这个模拟过程当中，这个作者使用了 QM/MM 的方法去模拟。"**

**QM/MM 方法原理** [92:36–93:14]：

> **"所谓的 QM/MM 的方法就是把这个体系分成两部分："**
> - **核心区域** → **用量子力学 DFT 去求解**
> - **非核心区域** → **用经验参数、用经典 MD 去模拟**

> ⭐ **理由**：**"这样的话我们就把我们所关心的、参与化学反应的这些部分模拟清楚、模拟得精确。周围的这些东西它只要提供一个环境就可以了，它具体跑得精不精确没什么太大的关系 —— 因为这个周围这些环境也不会发生化学反应，也不会发生化学键的断裂生成，所以说我们直接用这个 MM（经典力学）去跑。"**

⭐⭐ **Adaptive Buffer QM/MM（自适应缓冲）** [93:14–93:59]：

> **"在这个模拟过程当中，它有一个比较有意思的计算技巧，就是它可以动态地变化 QM 的区域和 MM 的区域。"**
> **"因为在模拟的过程当中必然会有水分子穿进来，也会有水分子穿出去。那么当这个水分子穿越到这个 QM 区域的时候，那就相当于它本来应该是 MM 区域的一个分子，现在它跑到 QM 区了，那么在做计算的时候就应该把它包含到量子区域的计算里面，把它从经典力学的计算里面给它删掉 —— 这样的话就是把这个 QM/MM 区域当做一个动态的变化。"**
> ✅ **"一般把这种方法叫做 Adaptive Buffer QM/MM 的模拟。这个方法也是可以在 CP2K 这个程序里面去实现的。"**

### 12.4 分子晶体：五唑盐的两种构型随温度变化 [93:59–95:49] ⭐

- 模拟对象：**炸药分子**，转写为"五错岩/五错盐"，即**五唑盐（N₅⁻，环里含五个氮原子）** `[94:08–94:16]`
- 🔧 该分子**非常容易爆炸，爆炸之后会产生很大的能量** `[94:16–94:20]`
- ⭐ **它有两种存在形式** `[94:20–94:36]`：

| 形式 | 结构 |
|---|---|
| ① | **纯的五个氮** |
| ② | **五个氮中有一个氮原子上结合一个氢原子** |

- **文章做法**：**"模拟了不同的温度，从 123 K 模拟到了 390 K，然后去比较在不同的温度下，这些五唑盐存在的状态的比例是什么样子的。"** `[94:36–94:55]`

**结果**：

| 温度 | 主导构型 |
|---|---|
| **123 K** | **以"不带氢"的方式存在的概率最大**（"它这个连氢的方式存在概率比较小"）`[94:55–95:05]` |
| **390 K** | ⭐ **趋势正好反过来了 —— 更有倾向于结合一个氢** |

> 🔧 讲师总结：**"在低温下它倾向于把这个氢给脱掉。"** `[95:15–95:19]`

⭐⭐ **为什么静态计算做不到** [95:19–95:47]：

> ⚠️ **"像这种计算我们在静态的计算模拟当中通过结构优化是肯定得不到的 —— 通过结构优化我们得到的只能是左边这种状态，因为我们没有办法把自由能的熵效应、还有它的一些动态的过程考虑进去。"**
> ✅ **"所以说我们在研究温度因素对材料的状态影响的时候，用 AIMD 动力学模拟是一个比较好的工具，可以考察这个温度效应的影响。"**

### 12.5 离子溶出 / 表面腐蚀与沉积 [95:49–97:21]

> **"这里还有一篇经典文献是模拟这个离子的溶出的，也就是材料表面的腐蚀或者是材料表面的沉积，都是一样的道理。"**

**机理**：

- **腐蚀**：溶液里有一些分子**可以把表面当中的一些原子给拔掉、把它溶解**；或者溶液当中有一些分子离子**可以把表面给氧化** `[96:00–96:16]`
- **沉积**：溶液当中有些离子、原子分子之类**可以沉积到表面上** `[96:18–96:23]`
- **都可以通过分子动力学模拟把这个自由能反应的势能面给它模拟出来** `[96:23–96:29]`

**文章做法** [96:29–97:04]：

- 用 **Metadynamics（元动力学）** 方法模拟了**氧化铝表面铝离子溶解**的过程
- **"通过设定这个配位数作为它的一个 collective variable（转写为'标的'），去一点一点地表征这个氧化铝表面铝粒子的配位数：从 3 一点一点地溶解出来，溶解到这个位置全部是水分子配位的，它不再和表面的氧去接触了。"**
- **"大约通过了 6 个（反应）步骤给它溶解出来了。"**

🔧 讲师预告：**"后面我们也会有一个例子去算这个金属表面的溶解，应该是一个 Pt（铂）的缺陷表面 —— 就是怎么用分子动力学模拟的方法去把这个金属表面的一个金属离子给溶解出来。"** `[97:04–97:21]`

### 12.6 有机化学反应的自由能势能面 [97:21–98:18]

> **"Metadynamics 这个方法还可以去算这个有机化学反应的这个自由能势能面。"**

以经典的 **SN2 反应**为例 [97:27–98:18]：

> **"在这个取代反应的时候，中间这个碳（碳氯物种），它一开始是和左边可能是个溴原子去接触的，然后它受到右边这个 CN（氰基）的进攻，它会发生 SN2 的反应。"**
> **"在发生这个 SN2 反应的时候，它会有一个化学键的断裂（旧的化学键断裂），这边新的化学键生成。然后我们去跟踪这两个化学键和自由能势能面的这个关系，我们就可以把这个自由能势能面给模拟出来，然后再去算他的自由能反应能垒。"**

### 12.7 固液界面：分子取向与电极电势 [98:18–99:47] ⭐

> **"AIMD 模拟还可以在一些固液界面体系发挥非常大的作用。这种计算模拟体系是最近几年兴起的一个研究领域。"**
> **"研究固液界面分子取向的排布 —— 而且这个分子取向的排布不一样，会影响到它的整个电子结构的性质，会影响到它后续的一些物理化学性质。"**

**现象** [98:51–99:35]：

| 条件 | 水分子的朝向 |
|---|---|
| **不加电势时** | **"比较无序的一种状态 —— 它有这个氢朝下的，也有这个氧朝下的，什么朝下的都有。"** |
| **改变金属电极的电势后** | ⭐ **"所有的这个氢都是朝下的，不会再存在这个氧朝下的这个状态。"** |

> ⭐ **"就是它通过一定的办法去改变这个电极的电势，从而改变了这个水分子的分子取向。这个分子取向改变了之后，对我们后续的表面的电化学反应会产生很大的影响。"**
> 🔧 举例：**"比如这个表面的 HER 反应的时候，这个水分子它是头朝下的还是它的羟基朝下的，对于它的整个反应过程的进行都是有一个能量上的影响的。"**

**⭐⭐ 密度自查（讲师强调的建模原则）** [134:56–136:00]：

> ⚠️ **"到底这个晶胞的大小合不合适、这个填的水分子数量合不合适？这个东西自己拿个计算器出来算一下：算一下水分子的质量，然后再算一下这个晶胞的体积，除一除看看这个密度是不是接近于 1 克每立方厘米。"**
> **"如果这个密度不合适呢，我们就可以调整水分子的数目，或者调整晶胞的大小了。"**

⭐⭐⭐ **为什么建模时就要把密度建对** [135:20–136:03]：

> **"这个建模的初始一定要把密度建得好一点。如果这个密度建得不好，那可能一开始我们还需要跑 NPT、跑那个控压的模拟，把它这个晶胞的体积跑合适，然后再去跑 AIMD —— 这个时候是非常麻烦的，我们跑 AIMD 又非常的耗时。"**
> ✅ **"所以说我们一开始在建模的时候就尽量把它的这个密度给建得非常的合适，正好是 1 克每立方厘米，这个时候我们连这个预平衡去平衡这个盒子大小都不用做了。"**
> ⭐ **"如果这个我们模拟体积的密度和真实实验上的密度是一样的，那这个时候我们就不需要去做 NPT 的预平衡了，直接去做这个 NVT 就可以去跑了。"**

#### B. ⭐ 异质结的两种建法 [144:33–152:10]

> **"固固界面这个模型建立方法有两种：一种是用 MS 去建，一种是用 VASPKIT 这个程序去建。"**

##### 方法一：VASPKIT（推荐，全自动）⭐⭐

> ⚠️ **"用 VASPKIT 这个程序去建这个固固界面的模型，也是在这个 1.2.0 这个新版本里面才刚出的这个功能。如果用老版的 VASPKIT 是没有这种异质结建模的功能的。"** `[144:46–144:58]`

**操作** [145:09–148:19]：

1. **"在我们并行科技（超算）里面就有装了这个 VASPKIT，在 `bin` 目录下有这个 VASPKIT，各个版本都有。我们用的是这个 1.2.0 这个版本。"** `[145:11–145:22]`
2. → 进入 **`examples`** → 里面有 **`heterojunction`** 文件夹 → **复制到自己目录** `[145:22–145:49]`
3. **准备两个结构文件**（异质结肯定是两个固体表面拼起来的）`[145:49–145:57]`
4. 🔧 本例给的两个例子：**一个是黑磷（black phosphorus）的单层**（"它这个晶胞层数很小，只有一个晶胞层数"）、**一个是 MoS₂**（转写为"硫化木"）`[146:06–146:29]`
5. ⭐⭐ **核心难点** [146:29–147:07]：

> **"他们两个这两个晶胞的形状是不一样的 —— 黑磷这个从 Z 这个方向上看下去，它这个正交形状是一个 90 度的；但是这个 MoS₂ 呢，我们从上面看下去呢，它是一个六方形式的，它的夹角是 60 度、120 度。"**
> ⚠️ **"我想要把这两个模型给摞起来建立成异质结，想要直接去摞肯定是不可能的，肯定是要对这个晶格矢量进行旋转 —— 就是对这个 MoS₂ 进行操作，把这个 MoS₂ 用一个转换矩阵，把它也变成一个正交的，然后才能把它给摞起来。"**
> ✅ **"这就是我们用 MS 建异质结的这个核心思想。"**

6. ⭐⭐ **VASPKIT 的自动化优势** [147:10–147:33]：

> **"如果我们用 VASPKIT 去建这种异质结的话，这个东西就比较的容易了，我们就不用去考虑这么多。因为 VASPKIT 去建异质结的时候，它会自动地去寻找两个材料的边长的最小公倍数，然后通过一系列的所有可能的这个转换矩阵的组合，然后去把所有有可能的异质结全都给它找出来，然后再让我们自己去挑选。"**

7. **操作步骤** [147:37–148:04]：

| 项 | 内容 |
|---|---|
| **功能** | **VASPKIT → 8 功能 → 804 功能** = 建立异质结 |
| **第 1 个输入** | **`mismatch` tolerance**（失配率容差） |
| ⭐ **建议值** | **"一般在 2% 或者 3% 之内，它是比较合理的"** |
| ⚠️ **超过 3% 的后果** | **"如果这个失配率超过了 3%，它有可能建立出来 —— 我们虽然模型可以建出来，但是建出来之后我们一优化，其中有一项就可能会崩塌掉，这个结构就会乱掉。"** `[148:04–148:15]` |
| 🔧 **柔性材料的例外** | **"当然有一些柔性的材料，它能够忍受的 mismatch 是比较大的。比如说像石墨烯这种（碳）材料，它的可弯曲性是比较好的 —— 像这种可弯曲性比较好的材料，我们去建这个异质结的时候，它的这个 mismatch 的容准度就比较大。"** `[148:15–148:30]` |
| **本例输入** | **"黑磷和 MoS₂ 其实它的可弯曲性还算可以，不是很差"** → **"这个 mismatch 我们这里输入 2 吧……要不就输入 0.5 吧，看看它能找出来吗"** `[148:33–148:47]` |
| 🔧 **策略** | ⭐ **"先输入个小点的 mismatch，如果小点 mismatch 找不出来，我们再扩大允许的适配率，然后再去找。"** `[148:46–148:53]` |
| **第 2 个输入** | **两个数值：`interlayer space` 与真空层** `[148:54]` |
| **`interlayer space`** | **"是我们这个异质结固固之间这两个材料之间的距离是多少。比如说输入个 2.5 Å，就代表我们这两个材料之间大约隔了 2.5 Å。"** `[148:56–149:03]` |
| ⭐ **真空层** | **"真空层代表着我们在建好这个异质结之后，在这个异质结的两端还要留出一定的空间，让它成一个真空的状态。那这个真空留多少呢？一般留 15 是比较好的。"** → **留 15 Å** `[149:08–149:21]` |
| **运行耗时** | **"这个过程大概会需要个几十秒钟，然后才能把这个所有的情况给辨认出来。"** `[149:33–149:37]` |

8. ⭐ **结果解读与权衡** [151:00–152:10]：

> **"由于输入 mismatch 要求是比较高的（必须要让它适配率在 0.5 以内），所以说它只找到了一个结果。"**
> ⚠️ **"就是找到这样一个异质结，这个异质结它超胞扩得很大 —— 这个很大的晶胞对于我们计算来说是不太有利的，这个晶胞太大了，我们优化出来就不太好做。"**
> ✅ **"这个时候我们可以去把这个 mismatch 稍微搞得大一点 —— 如果我们把 mismatch 搞得稍微大一点的话，它就可能会找到一些比较小的晶胞。就是适配率虽然有点大，但是它的这个晶胞会比较小，这个东西大家可以自己调节去做。"**
> 🔧 结果文件在 **`HeterojunctionList`**（转写为"Hardware Genius List"）里：**"有它的基本信息、转换矩阵 —— 这个是两个晶胞的转换矩阵；然后这个是它的这个晶胞的适配率、这个晶胞的角度、还有晶胞的边长，都是在这里有的。"** `[152:00–152:10]`

##### 方法二：MS 手工建（含晶格矢量旋转）⭐⭐

> **"还有一个程序建异质结模型的 —— MS 也可以建。"** `[152:10–152:17]`

**核心：晶格矢量旋转** [152:57–154:38]：

> **"晶格矢量的旋转，主要就是原理呢就是对它的这个晶格矢量做一个转换矩阵的变化。"**

⭐ **与"根号表面"的关系** [152:57–153:36]：

> **"有时候我们在文献当中会看到一些根号的晶面，其实原理是一样的，都是对这个晶格矢量做一个旋转的。像这里它旋转的 30 度就代表这个（√3×√3）R30°。"**
> **"√3 的意思是它的晶胞的边长变成了原本素晶胞边长的 √3 倍 —— 这就是代表 √3 × √3 × R30°。"**

**具体操作（把 MoS₂ 的六方转成正交）** [153:38–155:03]：

| 步骤 | 操作 |
|---|---|
| 1 | **Build → Symmetry → Redefine Lattice** `[153:43–153:48]` |
| 2 | ⭐ **讲师的方法论**：**"在 redefine lattice 这里我们可以去变换它的这个角度、变换它的这个旋转矩阵 —— 我们拿出笔来、拿出一张纸来画一画就知道该怎么转。"** `[153:48–154:17]` |
| 3 | 🔧 **几何推导**（画面/口述）：六方晶胞 A 方向与 B 方向夹角 120° → 要转成 90° | 
| 4 | ⭐ **新矢量 = 旧矢量的整数组合**：**"A 乘以 2（两倍的 a）加上一个 b，这就有了新的大 A 了；这个 b 不用变，这样就转出来了。"** `[154:17–154:38]` |
| 5 | 🔧 **矩阵写法**：**"新的这个晶格矢量大 A 我们需要用两个小 a 和一个小 b 给它组成 —— 这里大概要输 2（代表两个小 a）加上一个小 b，然后就生成了新的晶格矢量，然后这个 b 的晶格矢量不用变，然后再 redefine 一下，它就变成一个正交的晶系了。"** `[154:41–155:03]` |

**接下来：找最小公倍数 → 超胞 → Build Layers** [155:03–156:42]：

| 步骤 | 内容 |
|---|---|
| 1 | **读两个材料的边长**：**"A 是 5.52，B 是 3.19；再来看看那个 MoS₂、黑磷是多少 —— A 是 3.3，B 是 4.56"** `[155:03–155:19]` |

### CP2K 要点

1. **定位**：瑞士军刀，但**最强的是 AIMD**；优势在**大体系**（>100 原子）。
2. **编译三选一**：超算已装 / toolchain（易踩坑）/ ⭐ **讲师编译好的二进制**；**Ubuntu 可 `apt-get install cp2k`**。
3. **可执行版本**：**用 `popt`**；`ssmp` 慢 30–50%；`psmp` 仅内存紧张（HSE06）时考虑。
4. **作业三行**：`source` Intel 编译器 + `mpirun -n 56 cp2k.popt cp2k.inp 1>cp2k.out 2>cp2k.err`。
5. **版本**：用**稳定版 7.1**，别用测试版 8.0（"bug 实在太多了"）。
6. **四个缺点**：① 算**导体**慢（OT 不收敛）；② 磁性体系**必须手动指定自旋多重度**；③ **K 点不识别对称性** → 尽量只用 **Γ 点** → **晶胞边长要 ≥10 Å**；④ **BSSE 误差**（高斯基组带来，**高估吸附能**）。
7. **方法学**：**一篇文章可用两个程序**，CP2K 跑 AIMD + VASP 做精算，**扬长避短**。
8. **两个必看网站**：**cp2k.org**（手册，按版本对应）与 **Google Group 论坛**（报错第一去处，需科学上网）。
9. **推荐材料**：**周阿凡《CP2K 入门使用》**（十几页，强烈推荐）；**蓝金刚知乎专栏**。
10. **工具**：**VIM 插件**给输入文件上色，能一眼看出关键词拼错；⚠️ **CP2K 不识别缩进空格**（与 Python 不同）。

| **② 液体** | MS **Amorphous Cell → Construction** 或 **Packmol** | 水**密度 = 1**；边长默认 7.82³；**密度建对可省掉 NPT 预平衡** |

| **④ 固固（异质结）** | **VASPKIT 804**（自动）或 MS **Redefine Lattice + Build Layers** | **mismatch 2–3%**（柔性材料可放宽）；**interlayer 2.5 Å + 真空层 15 Å** |
| **⑤ 固液** | MS：切表面 → 建水盒 → **Build Layers** | ⚠️ **水盒 A/B 边长必须与表面一致**（本例 10.22×10.22）；Cu(111) 4 原子层 + 30 水分子 |
| **⑥ 气固** | 表面 slab 模型 | 讲师未展开（在 1-1/1-2 已讲吸附） |
| **⑦ 液液** | Packmol `inside box` 分半 + `centerofmass`/`fixed` 定位溶质 | 例：激素在水/氯仿界面 |
| **⑧ 气液** | 把固液模型的固体删掉即可 | 注意模型要够大 |

### 团簇建模
11. **负载团簇与真空中团簇建法相同**；**Au₂₀** 用**小铅笔 + Ctrl-C/Ctrl-V 逐层摞**（先 10 个原子的底，再 6 个，再 3 个）。
12. ⚠️ **建出来的只是初始结构**，真正最稳定构型需要**全局极小值搜索**。
