| T02 P48 | **Berendsen 热浴**：弱耦合到热浴 `dT(t)/dt = (1/τ)(T₀ − T(t))`；τ 是耦合参数，**τ 越大耦合越弱**，体系温度**指数式**趋向期望温度；`ΔT = (δt/τ)(T₀ − T(t))`；τ 被称为热浴的"**rise time**"，描述体系与假想热浴耦合的强度；τ→∞ 时恒温器需要极长时间才达到目标 T；**τ 太小则产生不真实的低温涨落**；`τ = δt` 退化为标准速度重标定。**"与速度重标定有同样的问题。"** |

| T02 P50 | **Langevin 热浴**：随机力源于环境分子的碰撞——不规则运动 + 摩擦。每步所有 v_i 被随机力与摩擦项修正：`m r̈_i = −∂U/∂r_i − mΓṙ_i + W_i(t)`；**摩擦与随机运动相关联，即满足涨落–耗散定理** `⟨W_i(t), W_j(t₀)⟩ = δ_ij δ(t−t₀) 6mΓk_BT`；高斯分布、相关时间无限短（碰撞次数极大）；给出过渡概率（Fokker–Planck 型）方程。 |
| T02 P51 | **随机行为**：`lim_{t→∞} P = C exp{−(1/k_BT)[Σ_i m p_i²/2 + U(r^N)]}`——**恢复正则分布**；摩擦与扩散相关 `D = (Γ/m) k_B T`；**局部恒温器**：噪声项依赖于粒子。三条评价：**从正则系综采样且遍历；相比非随机恒温器允许更大的时间步长；动量传递被破坏，即（拿不到）扩散系数**。 |
| T02 P52 | **Nosé 热浴**：热浴是体系的积分组成部分，变量 s、ṡ 与 Q（耦合）：`L = Σ_i (m s² ṙ_i²)/2 − U(r^N) + ½Qṡ² − g k_B T ln s`；共轭动量 `p_i ≡ ∂L/∂ṙ_i = m s² ṙ_i`、`p_s ≡ ∂L/∂ṡ = Qṡ`；辅助变量是时间标度参数 `dt₀ = s dt`、真实体系动量 `p_i⁰ = p_i/s`；**扩展体系取微正则系综：当 `g = 3N+1` 时，真实体系为正则系综**。 |
| T02 P53 | **Nosé–Hoover**：只用真实时间 t 微分（`1/(s dt₀)`）：`ṙ_i = p_i/m_i`；`ṗ_i = −∂U/∂r_i − ξ p_i`，`ξ = s p_s/Q`；`ξ̇ = (1/Q)[Σ_i p_i²/m_i − g/β]`；`ṡ/s = dln s/dt = ξ`；**守恒量** `H_Nosé = Σ_i p_i²/2m_i + U(r^N) + ξ²Q/2 + g ln s/β`。 |
| T02 P54 | **摩擦系数**：定义弛豫时间 `ν_T ≡ √(3Nk_BT/Q)`；摩擦系数动力学（反馈机制）`ξ̇ = ν_T²[(Σ p_i²/m_i)/(3Nk_BT) − 1] = ν_T²[T/T₀ − 1]`。**Q 太大：要跑很久才有正则分布；Q 太小：高频 T 振荡**。 |

| T02 P64 | **Berendsen 压浴**：偏离目标压强 `dP(t)/dt = (P₀ − P(t))/τ_P`（τ_P 弛豫时间）；把体积按 η 标度、坐标按 `η^{1/3}` 标度：`η(t) = 1 − (δt/τ_P)γ(P₀ − P(t))`（γ 是压缩率）；可各向同性或各向异性；τ_P 是耦合强度；**"系综分布不正确"**。 |

| T02 P66 | **正确分布**：6N+2 维体系的守恒哈密顿量 `H = Σ_i π_i²/(2m_iΩ^{2/3}) + Π²/2W + U(s^N,Ω) + PΩ`；**W 小 → 盒尺寸快速振荡；W 大 → 体积调整缓慢**；配分函数 `Δ(N,P,H) = ∫dΩ∫dΠ∫dπ^N∫ds^N δ(H + Π²/2W − H)`；**轨迹与 NPH 系综一致**；**与任一恒温方法组合即可做 NPT 系综**。 |

| T04 P3 | "优化"是什么：最小化总能量（aka relaxation）。总能量是原子位置的函数；DFT 中 `E_tot[n(r)]` 且 `n(r) ⇔ V(R)`（**Hohenberg–Kohn**）。分子力学中有力场 `U(R) = Σ_bond V_bond(R_i,R_j) + Σ_angle V_angle(R_i,R_j,R_k) + …`。 |
| T04 P4 | 优化什么？0 K 下体系的总能量（DFT 中 = 势能 + 电子动能），或有限温度下的自由能。可把势能想成 **3N 维空间中的一张曲面**（N 为原子数）；**PES —— Born–Oppenheimer 近似**；**若计入周期性体系的晶格矢量，就是 3N + 9 维！**极小值可能是局域的或全局的。 |

| T04 P13 | 用时间离散化求解运动方程：给定 t₀ 时刻的位置 R 与速度 V，`R(t₀)→R(t₀+∂t)→R(t₀+2∂t)…`，`V(t₀)→V(t₀+∂t)→…`。要的方案：**高效**（最少力计算次数、最少存储数据）／**稳定**（守恒量漂移最小）／**准确**（离精确轨迹最近）。 |
| T04 P14 | **Velocity Verlet**：`r_i(t+∂t) → r_i(t) + ∂t·v_i(t) + (∂t²/2m_i) f_i(t)`；`v_i(t+∂t) → v_i(t) + (∂t/2m_i)[f_i(t) + f_i(t+∂t)]`。**高效：1 次力计算、3 个存储量；稳定：时间可逆；准确：辛（symplectic）、积分误差 O(∂t²）**。扩展：约束（**SHAKE, RATTLE, ROLL**）、多时间步（**r-RESPA**）与恒温器。 |

## 3. 核心逻辑链（重点）

### 3.0 一句话主干

```
BO 近似 ⟹ 每步求电子基态(SCF) ⟹ 力 = −∇E_BO ⟹ Velocity Verlet 积分 ⟹ NVE 微正则
                                                    │
              ┌─────────────────────────────────────┴──────────────────────────────────┐
              │ 但 SCF 永远收敛不到机器精度 ⟹ BO 面被"抖动" ⟹ 力有噪声 ⟹ 能量漂移（人为加热）│
              └─────────────────────────────────────┬──────────────────────────────────┘
                                                    │
        必须外推波函数以省 SCF ⟹ 外推必须【时间可逆】⟹ ASPC(k)（而不是 Gear/PS）
                                                    │
              控温/控压 ⟹ 从四种控制范式选一种 ⟹ 只有 Nosé-Hoover 链 / Langevin(CSVR) 能给出正确系综
```

### 3.1 BOMD 的理论骨架（因果链）

**(a) BO 近似：为什么可以"先解电子、再动核"**

`离子质量 ≫ 电子质量 ⇒ （经典）核与（量子）电子运动方程可分离`（T04 P15）。
于是构造 **BO 势能面** `V(R) = min_Φ [ E_KS({Φ(r)}; R) + const. ]`（T02 P11），
核就在这张面上按纯经典牛顿方程走：`M_I R̈_I = −dV(R)/dR_I`（T02 P3/P11、T04 P12）。

**(b) 电子步 / 离子步的嵌套：力为什么正好是 Hellmann–Feynman 力**

```
f_KS(R) = d/dR min_Φ E_KS({Φ(r)};R)
        = ∂E_KS/∂R + ∂const./∂R + Σ_i [∂(E_KS+const.)/∂Φ_i]·(∂Φ_i/∂R)
                                            └────────── = 0 ──────────┘
```
（T02 P11、T04 P15）
**中间那一项为零，正是因为 Φ 在变分意义下已最优**（`∂E/∂Φ = 0`）。
这条推导是整个方法论的枢纽：**只要电子结构真的收敛到变分极小，力就只算 ∂E/∂R 一项**；
反之，**SCF 没收够 ⟹ 该项不再是零 ⟹ 多出来的部分就是"非自洽误差力" f_nsc**，
它是后面一切稳定性问题的总根源（T02 P20、P26）。

**(c) 运动方程：一个拉格朗日量统摄三种 AIMD**

Hutter 只用**一个广义拉格朗日量**（T02 P15，Niklasson 推广，PRL 100, 123004 (2008)）：

```
L(q,q̇,x,ẋ) = ½Mq̇² + ½µẋ² − E(q,y) + kµG(‖x−y‖),      y = F(q,x)
```

| 取法 | 得到什么 | 页码 |
|---|---|---|
| `y = x`（即 `G(‖x−y‖)=0`），µ ≠ 0 | **CPMD**：`Mq̈ = −∂E/∂q`、`µẍ = −∂E/∂x` | T02 P17 |
| `y = min_x E(q,x)` 且 **`µ = 0`** | **BOMD**：电子部分独立，运动方程**解耦** `Mq̈ = −∂E/∂q`、`ẍ = −k∂G/∂x` | T02 P19 |
| `y = F(q,x) ≈ min_x E(q,x)` 但 µ = 0（SCF 没收够） | **两方程通过被忽略的耦合项重新耦合** | T02 P20 |

> **因果链的关键一步**：BOMD 不是"另一个方法"，它是**同一个拉格朗日量在 µ → 0 时的极限**。
> 代价是：CPMD 里 µ 是一个**可调旋钮**（离 BO 面多远由 µ 控制，T02 P18），
> 而 BOMD 里 **µ = 0 把旋钮拿掉了**——BO 面的准确性**完全**由 `ε_SCF` 承担。
> 这就解释了为什么 Hutter 花整整两页（P26–P29）去修"近似 BO 力"。

**(d) 积分器：为什么是 Velocity Verlet**

```
R(t+τ) = R(t) + τV(t) + (τ²/2M) f(t)
V(t+τ) = V(t) + (τ/2M)[ f(t) + f(t+τ) ]
```
（T02 P8、T04 P14）
三个标准一次满足（T02 P6、T04 P13）：

| 标准 | Verlet 的表现 | 为什么 |
|---|---|---|
| 效率 | **1 次力计算 / 步，3 个存储向量** | 力只在当前时刻算一次；`f(t+τ)` 下一步复用 |
| 稳定性 | **时间可逆**（且辛，T04 P14） | 辛积分器不产生**长期**能量漂移（只产生有界振荡） |
| 精度 | **`O(τ²)`** | 短时误差展开阶 |

四类误差来源（T02 P7）：积分器类型 / 时间步长 τ / **力与能量的一致性**（例：截断让能量面不光滑）/
**力的精度**（迭代力计算的收敛）。**AIMD 里后两类是主要的，不是积分器本身。**

**(e) 系综与控温：四种控制范式 → 具体恒温器**

Hutter 把"控温"归成四种范式（T02 P42），后面所有恒温器都是其中之一：

| 范式 | 手段 | 后果 | 对应恒温器 |
|---|---|---|---|
| **微分控制** | 温度钉死在指定值 | **完全没有涨落** | （理想化，不实现） |
| **比例控制** | 每步用耦合常数把速度朝 T₀ 修正 | **耦合常数决定 ⟨T⟩ 附近涨落的强度** | 速度重标定（P45）、Berendsen（P48） |
| **积分控制** | 扩展哈密顿量，引入反映外系统作用的变量 | 从扩展哈密顿量导出时间演化 → 可得到**正确分布** | Nosé（P52）、Nosé–Hoover（P53）、NHC（P56）、Andersen 压浴（P65） |
| **随机控制** | 带摩擦 + 随机力的修改运动方程 | **给出正确的温度平均值**（涨落–耗散定理保证） | Langevin（P50）、CSVR |

**系综—热力学势对应**（T02 P59）：NVE→U；NVT→`F = U − TS`；NPH→`H = U + pV`；NPT→`G = U − TS + pV = H − TS`。
**T04 P25/P26 给出"守恒量该看什么"的直接答案**：
NVT 下**总能量不再守恒**，守恒的是"**体系能量 + 热浴能量**"；NPT 下再加"**压浴能量**"。
⟹ 这就是 §3.3 里"检查 `PROJECT.ener` 的哪一个量"的判据来源。

### 3.2 实用判据的来历（要"为什么"，不只给数）

#### (1) 时间步长怎么定 —— 判据来自"离散化误差 + 最快运动周期"

**不是**经验口诀，而是两条硬约束叠起来：

1. **积分误差 `O(τ²)`**（T02 P8、T04 P14）：τ 减半，短时误差降 4 倍。
2. **时间步长必须分辨最快的相关核运动**（G 层 `04_sampling_md.md` §9.1 同口径；
   T02 的对应硬证据是 P12 的**基准体系参数：64 水、330 K、τ = 0.5 fs**）。
   物理上：一步内原子位移必须远小于振动振幅，否则"一步跨过势能面的弯折"，
   力失去意义 ⟹ 温度飙升/键断裂。

**AIMD 特有的第三个约束**（这条是 BOMD 独有的，经典 MD 没有）：
**SCF 外推的"插值半径"受 τ 限制**。外推用前 K 个离子步的波函数预测下一步初猜（T02 P21–P22），
τ 越大，相邻离子步的几何差别越大，外推越差 ⟹ SCF 迭代越多、`f_nsc` 越大、漂移越大。
所以 **τ 同时被"振动周期"和"外推有效性"两头夹**。

> **判定方法（可执行）**：跑**短的 NVE 轨迹**（T02 P74 / T04 P22 / G 层 §9.2），
> 看总能量振荡与长时间漂移相对于动能（目标温度）是否很小。
> **H 层提供的定量标尺**见下表 👇

#### (2) 能量守恒 / 漂移的判据 —— 为什么是 0.1 ~ 0.4 K/ns 这个量级

**漂移从哪来？** 精确的 BO 面上力 = −∇E_BO；实际算的力带**非自洽误差** f_nsc（T02 P20、P26）。
若 SCF 误差在相邻步之间**随机**，则体系每一步被"随机踢一下" ⟹ 能量做**随机游走**：
`E(t) = E(0) + Σ_i δE_i`，故**漂移幅度 ∝ √(步数) ∝ 1/√τ**（τ 越小、步数越多、漂移越大）。
这就是为什么"漂移"必须按**单位时间**（K/ns）而不是按步报。

**ASPC(3) 在 1e-6 上给出"迭代 5.01 + 漂移 0.2"这个双赢点**——
比无外推的 14.38 次迭代省 65%，比 Gear(4) 同阶漂移低 30 倍。
**这就是 CP2K 把 ASPC(3) 设为默认的全部理由**（T02 P74、T04 P22）。

**为什么 Gear(4) 不行？（"时间可逆性"这条判据的来历）**

Hutter 的论证链（T02 P14 → P21 → P23、T04 P19 → P20）：
1. Gear 预测子精度**更高**（4 阶），迭代次数**更少**（P14：Gear(4)@1e-6 = 5.22 < ASPC(3)@1e-6 = 5.01 同量级）。
2. **但 Gear 不是时间可逆的**（P14 的原话反问："What is the problem? Time reversibility has been broken!"）。
3. **时间可逆被破坏 = 误差变成系统性的而不是随机的**：
   - 可逆（ASPC）：把轨迹倒着积分应回到出发点 ⟹ 外推引入的误差必须**反对称**，
     在正向/反向时间平均下**抵消**，只留下 `O(τ^{2k+1})` 的有界振荡。
   - 不可逆（Gear/PS）：误差**有固定符号** ⟹ 沿轨迹**单向累积** ⟹ 表现为**漂移**。
4. 数值证据（同 ε_SCF = 1e-5）：ASPC(3) = **4.5 K/ns**，Gear(4) = **86.8 K/ns**——**差 19 倍**。
   同 ε_SCF = 1e-6：ASPC(3) = **0.2**，Gear(4) = **11.8**——**差 59 倍**。
5. 解决手段：**ASPC（Always Stable Predictor Corrector）**，
   出处 **J. Kolafa, J. Comput. Chem. 25: 335–342 (2004)**，
   关键性质 **`ASPC(k)` 时间可逆到 `2k+1` 阶**（T02 P21）。
   **"Always Stable"这个名字本身就是"可逆 ⟹ 不漂移"的另一种说法。**

> **⟹ 判据的可迁移形式**：任何"为了效率而引入的近似"（波函数外推、力校正、稀疏化），
> **只要它破坏了时间可逆性，就一定会转成漂移**。ASPC 是这条原则在 AIMD 中的标准解。

**外推阶数怎么选（P24–P25，T04 P21）**——为什么默认是 3 而不是越大越好：

| ASPC 阶 k | ε_SCF = 1e-4 时的漂移 [K/ns] | 迭代次数 |
|---|---|---|
| 4 | 1742.4 | 1.62 |
| 5 | 1094.0 | 1.63 |
| 6 | 397.4 | 1.79 |
| 7 | 445.8 | 1.97 |
| 8 | **24.1** | 2.06 |

- 在同一 `ε_SCF = 1e-6` 下，ASPC(3) 与 ASPC(4) **完全相同**（5.01 / 0.2，T02 P23 vs P24）
  ⟹ **k = 3 已经够用**，加阶数只增开销不加稳定。
- 只有当 `ε_SCF` 被迫放到 `1e-4` 这种松值（金属、大体系、慢 SCF）时，
  **阶数才变成救命稻草**：k = 8 把 1742 → 24.1 K/ns（降 72 倍），代价是迭代 1.62 → 2.06。
- 但注意**非单调**：k = 6 (397.4) 比 k = 7 (445.8) 还好 ⟹ **"更高阶不一定更好"**，
  与 G 层记录的官方经验（"金属体系用 `EXTRAPOLATION_ORDER 0` 更稳定"，
  `24_official_exercises.md` §2.2）并不矛盾——**最优阶数依体系而定，必须实测**。

**正交性约束：为什么外推要写成 `C^T S C` 的形式**

`C_init = Σ_{j=0}^{K} B_{j+1} C_{t−jτ} C^T_{t−jτ} S_{t−jτ} C_{t−τ}`（T02 P22）。
- `S` 是**重叠矩阵**（非正交基组）。
- `C^T_{t−jτ} S_{t−jτ}` 是"把过去第 j 步的系数投影到当前重叠度规上"。
- **为什么需要**：预测出来的 `C_init` 必须**仍然满足正交归一**（否则第一步 SCF 就从非法态起步）。
  直接在系数空间做线性组合会破坏正交性；**乘上重叠矩阵的投影才保证 `⟨C_init|S|C_init⟩ = I`**。
- 出处 **VandeVondele et al., Comp. Phys. Comm. 167: 103–128 (2005)**（T02 P22、T04 P20）。

#### (3) 控温器为什么这么选 —— 从"能给出正确系综"倒推

**判据不是"哪个控温更稳"，而是"哪个控温给出的分布是对的"**（T02 P58 总表）：

| 恒温器 | 正确分布？ | 遍历？ | 守恒量？ | 确定性？ | CP2K 关键字 | 页码 |
|---|---|---|---|---|---|---|
| 速度重标定 | ✗ | ? | — | ✗ | **无** | T02 P45、P58 |
| Andersen | ✗ | ✗ | ✗ | ✗ | （无） | T02 P58 |
| Berendsen | ✗（"G ?"= 仅"大致"） | ✗ | ✗ | ✗ | （无独立关键字） | T02 P48、P58、P64 |
| **Nosé–Hoover** | ✓ | ✗ | ✗ | ✗ | **`NOSE` + `LENGTH=1`** | T02 P53、P58 |
| **Nosé–Hoover 链** | ✓ | ✓ | ✓ | ✓ | **`NOSE`** | T02 P56、P58、T04 P32 |
| **Langevin** | ✓ | ✓ | ✗ | ✗ | **`CSVR` + `MASSIVE`** | T02 P50、P58 |
| 随机速度重标定 | ✓ | ✓ | ✗ | ✗ | **`CSVR`** | T02 P58 |

> **⚠️ 这张表的列头被抽取破坏**（`tune cont. L/G correct ergodic cons. q. determ. cp2k`），
> 上面按语义还原的列名（正确分布/遍历/守恒量/确定性）**属于推断**，见 §7 存疑 #3。
> 但**行内容与 CP2K 关键字脚注是原文照抄**，可放心引用"哪种方法对应哪个 CP2K 关键字"。

**逐条"为什么"**：

- **速度重标定 ✗**（T02 P45）：它把 `T(t)` 强行钉到 `T₀`，**涨落被人为抹掉** ⟹
  "**Sampling does not correspond to any ensemble**"。所以 Hutter 的三条评语是：
  **不推荐用于生产、适合平衡、非时间可逆非确定性**。T04 P28 用 CP2K 语言复述了同一件事：
  `TEMP_TOL 10`（T<290 或 T>310 才重标定）**"不产生正则系综；只用于平衡"**。

- **Berendsen ✗**（T02 P48）：指数式弛豫 `dT/dt = (T₀−T)/τ` 看着很美，
  但 Hutter 两句关键评语：**"τ 太小 → 产生不真实的低温涨落"**、
  **"Same problems as velocity rescaling"**。P49 进一步把它写成摩擦形式
  `ṗ_i = f_i − ζp_i`，并指出 **"当 `T > Nk_BT/2` 时摩擦为正 ⟹ 制冷"**——
  即它本质上是一个**确定性的、单向的**的制冷/加热器，**没有对应的涨落项**，
  ⟹ **涨落–耗散定理不满足 ⟹ 分布不对**。同一逻辑在压浴上重现（P64：**"not correct ensemble distribution"**）。

- **Langevin ✓ 但代价明确**（T02 P50–P51、T04 P30–P31）：
  **为什么分布对**——`m r̈_i = −∂U/∂r_i − mΓṙ_i + W_i(t)`，
  且 **涨落–耗散定理**`⟨W_i(t),W_j(t₀)⟩ = δ_ij δ(t−t₀) 6mΓk_BT`（P50）。
  **摩擦与随机力由同一个 Γ 绑定**，所以 `lim_{t→∞} P = C exp{−(1/k_BT)[Σ mp²/2 + U]}`（P51）
  ——**正则分布是它的不动点**，不是人为钉的。
  三条代价（P51 / T04 P31）：①**允许比非随机恒温器更大的时间步长**（优点）；
  ②**动量传递被破坏 ⟹ 拿不到扩散系数**（缺点，T04 P31 措辞："只对采样有用，不能用于动力学性质如扩散"）；
  ③**局部恒温器**——噪声项依赖粒子（P51）。

- **Nosé–Hoover ✓ 但会"卡在子空间"**（T02 P52–P56）：
  **为什么分布对**——把热浴做成体系的**积分组成部分**：
  `L = Σ (ms²ṙ²)/2 − U(r^N) + ½Qṡ² − gk_BT ln s`（P52），
  再做时间变换 `dt₀ = s dt`、`p_i⁰ = p_i/s`（P52），
  **"扩展体系取微正则系综：当 `g = 3N+1` 时，真实体系为正则系综"**（P52）。
  **⟹ 关键：`g = 3N+1` 不是随便取的**，它是让扩展体系的微正则投影回真实体系时**恰好**得到正则分布的计数。
  P53 给出可直接积分的 Nosé–Hoover 形式与**守恒量**
  `H_Nosé = Σ p²/2m + U(r^N) + ξ²Q/2 + g ln s/β`（**这就是 §3.3 里"检查能量"要检查的那个量**）。
  **遍历性为什么出问题**（P55）：**"Nosé–Hoover：由初始条件决定的带状轨迹。混沌性不足，无法采遍整个相空间；被囚禁在子空间里。"**
  **解药 = 给恒温器本身再加恒温器**（P56）：`ξ̇₁` 中多一项 `−ξ₁ξ₂`，链条往下传**（Nosé–Hoover chain）**。
  T04 P33 用一句话概括：**"遍历（仅 N-H 链）"**。
  ⟹ **这就解释了 CP2K 为什么把 `LENGTH` 默认成 3 而不是 1**（T04 P34：
  "**取 1 则回到原始 Nosé 恒温器**"）：
  **`LENGTH=1` 就是那个会卡在子空间里的版本**，与 T02 P58 表脚注
  "Nosé-Hoover ⟹ `NOSE`（**use `LENGTH=1`**）" 完全对应。

- **Q / `TIMECON` 怎么选——不是手感，是从 `ν_T` 推出来的**（T02 P54、T04 P34）：
  定义弛豫时间 `ν_T ≡ √(3Nk_BT/Q)`，则摩擦系数按**反馈机制**演化
  `ξ̇ = ν_T²[T/T₀ − 1]`。**⟹ Q ↔ 弛豫时间是一一对应的**，
  所以 CP2K 干脆让你直接给时间：`&NOSE TIMECON 1000 [fs]`
  （T04 P34："**1000 fs 是目标弛豫时间**"；`LENGTH 3` 默认）。
  Hutter 的双向警告（P54）：**"Q 太大 → 要跑很久才有正则分布；Q 太小 → 高频 T 振荡"**。
  T04 P35 把它翻译成操作：**"用小的 `TIMECON` 做快速平衡；默认值通常对生产 MD 够用。"**
  ⟹ **同一参数在不同阶段取不同值**：平衡期要"强耦合"（小 τ），生产期要"弱耦合"（大 τ）。

- **为什么"分布正确"比"温度稳"更重要**（贯穿 P57–P58）：
  P57 的对比图显示速度重标定/Berendsen 的温度曲线**看起来**也可以，
  但 P58 的表判定它们 **correct = ✗**。**⟹ 判据必须看分布，不能看曲线好看。**
  这与 G 层官方口径一致但**给出了物理理由**：G 层只写"CSVR 往往是更安全的实用默认选择"
  （`04_sampling_md.md` §7.1），H 层补上了**"为什么 NOSE 默认但不推荐给新手"**——
  因为 `LENGTH` 的遍历性问题 + 弛豫时间需要调。

#### (4) BOMD + 不完整 SCF：Langevin BOMD / SGCP（H 层最"新"的理论）

这条链是 H 层独有的、A–G 层**只登记了结论没有推导**的部分：

```
力分解(T02 P26)      f(R) = f_BO + f_HF + f_Pulay + f_nsc
                                        └── 正确 BO 力 ──┘   └ 非自洽误差 ┘
近似 f_nsc(T02 P27)  f̃_nsc = −∫dr [ (∂V_xc(ρ_i)/∂ρ_i)·Δρ + V_H(Δρ) ] ∇ρ_i,   Δρ = ρ_o − ρ_i
                     （ρ_o = 输出密度，ρ_i = 初始/预测密度）
把它当摩擦(T02 P27)  f(R) + f̃_nsc(R) = f_BO(R) − γ_D·Ṙ
Langevin EOM(P28)    MR̈ = f_BO(R) − (γ_D + γ_L)Ṙ + Θ
涨落–耗散(P28)       ⟨Θ(0)Θ(t)⟩ = 6(γ_D + γ_L) M k_B T δ(t)
温度定义(P28)        T = (k_B/3)⟨MṘ²⟩
```

**因果要点**：
1. **`f_nsc` 是可以"算出来"的**（P27 的积分式），不必只是"承认它存在"。
   `Δρ = ρ_o − ρ_i` 就是这个离子步 SCF 没走完的距离——**SCF 越不收敛，Δρ 越大，f̃_nsc 越大**。
2. **把 `f̃_nsc` 当成摩擦 `−γ_D Ṙ`** 是一个**物理上的等价替换**：
   原本是"确定性的、每步方向固定的误差力"，换成"耗散项"。
3. **替换之后必须补一个随机力 Θ 来维持正则分布**——这正是涨落–耗散定理的作用（P28）。
4. **γ_D 不是自由参数**：给定目标温度 `T = (k_B/3)⟨MṘ²⟩` 与任意 γ_L，
   **由涨落–耗散关系"反解"出 γ_D**（P28 原话：**"this determines γ_D"**）。
   ⟹ **你选的每个 γ_L 都被 γ_D 自动补偿，所以统计仍然正确**：这就是 SGCP 的合法性来源。
5. **SGCP（第二代 Car–Parrinello）**（P29，T. D. Kühne et al., PRL 98, 066441 (2007)）：
   **只需单次 SCF 步 + 力校正**；对 SCF 收敛慢的体系极其高效；
   **γ_D 很小 ⟹ 统计与动力学正确**；**但在复杂体系中难以稳定**。
6. 性能演示：液态硅 3000 K 的力误差分析（T02 P30，Musso et al., EPJ B 91, 148 (2018)）；
   h-BN/Rh(111) 纳米网（P31–P34）。**具体数字在图里，文本层拿不到。**

> **⟹ 判据的第三层含义**：`ε_SCF` 的收紧**不是唯一出路**。
> 若体系 SCF 天然收敛慢（金属、大 gap 小的体系、大体系），
> **可以用"松 SCF + Langevin 力校正"换取效率**，代价是 γ_D 要调、复杂体系可能不稳定。
> CP2K 的落点是 `&MD &LANGEVIN` 下的 `NOISY_GAMMA`(γ_D) 与 `GAMMA`(γ_L)
> （G 层 `24_official_exercises.md` §2.2 参数表；H 层给出**这两个参数为什么存在**）。

#### (5) 压浴：同一套逻辑在压强上的复刻

| | Berendsen 压浴 | Andersen 压浴 |
|---|---|---|
| 做法 | 弱耦合，按 η 标度体积、`η^{1/3}` 标度坐标（T02 P64） | 给体积配动能 `½WΩ̇²`，模拟质量 W 的活塞（T02 P65） |
| 公式 | `dP/dt = (P₀−P)/τ_P`；`η(t) = 1 − (δt/τ_P)γ(P₀−P(t))` | `WΩ̈ = 3Ω[Ω^{2/3}Σmṡ² − Σs·∂U/∂s] − P = P_int − P` |
| 分布 | **✗ "not correct ensemble distribution"**（P64） | **✓ 轨迹与 NPH 系综一致**（P66） |
| 守恒量 | 无 | `H = Σπ²/(2mΩ^{2/3}) + Π²/2W + U(s^N,Ω) + PΩ`（6N+2 维，P66） |
| 参数含义 | `τ_P` = 耦合强度（P64） | **`W` = 活塞质量 = 耦合强度**（P65）；**W 小 → 盒尺寸快速振荡；W 大 → 体积调整缓慢**（P66） |
| 与热浴组合 | — | **"与任一恒温方法组合即可做 NPT"**（P66） |

**为什么需要维里定理**（T02 P61）：压浴的驱动力是**瞬时内压**，
而内压不是"算出来的一个数"，是**从能量均分定理推出来的统计量**：
`⟨3pV⟩ = 2⟨H_kin⟩ − ⟨Σ_i r_i·∂V(r)/∂r_i⟩`。
推导路径：能量均分 `⟨H_kin⟩ = ½⟨Σ r_i ∂U/∂r_i⟩` → 把 U 拆成内部势 `V_int` 与壁势 `W`
→ `⟨Σ r_i ∂W/∂r_i⟩ = ∫p df·r = ∫p dV(div r) = 3pV`。
**⟹ 压强是"对壁的力"的统计平均，不是局域量**，所以 `p(t)` 必然剧烈涨落（T02 P60：
"瞬时压强 p(t) 涨落、对容器有力；对 p(t) 取平均得到可观测的内压"）。

T02 与 T04 的口径完全一致：**T04 P35"压浴几乎有同样的选项：`MOTION%MD%BAROSTAT`"**。

```text
体系：64 个水分子（192 原子）
密度        1 g cm⁻³
温度        ≈ 330 K
时间步长     0.5 fs
方法        GPW
基组        TZV2P（2560 个基函数）
泛函        PBE
CUTOFF      280 Rydberg
ε_default   1e-12
SCF 求解    OT-DIIS
预条件器     FULL_SINGLE_INVERSE
参考轨迹     1 ps，ε_SCF = 1e-10
```
> 注意 `CUTOFF 280 Rydberg` 是**这套基准的取值**，不是推荐默认（默认值以 G 层为准）。

### 4.2 CP2K 的 BOMD 默认与推荐（T02 P74，原文照抄）

```
Born–Oppenheimer MD with ASPC(3) is default in CP2K
SCF convergence criteria depends on system
  1e-5 ... 1e-6 is a reasonable starting guess
Best used together with OT and the FULL_SINGLE_INVERSE preconditioner,
for large system an iterative update of the preconditioner should be used
  PRECOND_SOLVER INVERSE_UPDATE
Langevin dynamics is an option
  needs some special care, analysis of forces
```
（T04 P22 的同义表述：**"Defaults settings are ASPC(3)"、"SCF tolerance for 'acceptable' drift is
system-dependent but EPS_SCF 1E-5 or 1E-6 is a good guess"、"Use OT and appropriate preconditioner
to speed up SCF"**。）

### 4.3 波函数外推：PS（错）vs ASPC（对）

**❌ 会被破坏时间可逆性的写法**（T04 P19）：
```
&QS
  EXTRAPOLATION PS
  EXTRAPOLATION_ORDER 4
&END QS
```
**✅ 正确写法**（T04 P20，CP2K 默认）：
```
&QS
  EXTRAPOLATION ASPC
  EXTRAPOLATION_ORDER 3
&END QS
```
> 同 ε_SCF=1e-5：PS/Gear(4) 漂移 **86.8 K/ns**，ASPC(3) 漂移 **4.5 K/ns**（T02 P23）。
> `EXTRAPOLATION` / `EXTRAPOLATION_ORDER` 的**默认值与取值枚举以 G 层为准**
> （`04_sampling_md.md` §11.1、`05_optimization.md`），此处只给 H 层的"为什么"。
