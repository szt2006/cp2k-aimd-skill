## 1. `&GLOBAL` 段定位

官方定义：

> **GLOBAL** — Section with general information on which kind of simulation to perform and parameters for the whole PROGRAM

即：**决定"这次算什么"，以及影响整个程序的全局参数**。它必须写在输入文件里（顶层段之一），且是唯一一个不属于 `FORCE_EVAL` / `MOTION` 的运行控制段。

顶层段共两个常用块（官方静态计算教程原文）：

- `GLOBAL`：运行的一般选项，如作业名称、运行类型；
- `FORCE_EVAL`：与原子受力评估相关的所有参数，包括初始原子坐标。

官方补充说明：**输入文件由有序的块（block）与关键字（keyword）组成，各块的先后顺序不重要**。每个块称为 section（段），部分 section 是其他 section 的 subsection（子段）。

## 2. `&GLOBAL` 全部 38 个关键字

> 以下按官方页面顺序，逐条给出**类型 / 默认值 / 别名 / 用法 / 官方描述 / 可选值**。
> 标 ⭐ 的是官方重点标记项。

### 2.1 运行控制（最常用）

#### `PROJECT_NAME` ⭐
- **类型**：string　**默认**：`PROJECT`　**别名**：`PROJECT`
- **用法**：`PROJECT_NAME {STRING}`
- **官方描述**：Name of the project (used to build the name of the trajectory, and other files generated by the program)
- **要点**：所有自动生成的输出文件都以它作前缀。重启波函数时必须与新计算共享同一 `PROJECT_NAME`。

#### `RUN_TYPE` ⭐
- **类型**：enum　**默认**：`ENERGY_FORCE`
- **用法**：`RUN_TYPE MD`
- **官方描述**：Selects the top-level task CP2K should run, such as an energy, energy-and-force, molecular dynamics, geometry optimization, or response calculation.
- **完整取值表**见本文 §3。

#### `PRINT_LEVEL` ⭐
- **类型**：enum　**默认**：`MEDIUM`　**别名**：`IOLEVEL`
- **用法**：`PRINT_LEVEL HIGH`
- **官方描述**：How much output is written out.
- **可选值**：
  - `SILENT` — Almost no output
  - `LOW` — Little output
  - `MEDIUM` — Quite some output
  - `HIGH` — Lots of output
  - `DEBUG` — Everything is written out, useful for debugging purposes only
- **注意**：可在各子段中覆盖此设置以微调输出详细程度（官方静态计算教程）。
- **官方在多处提及**：`cutoff.html` 建议用 `PRINT_LEVEL MEDIUM` 看 MULTIGRID INFO；`ri_kpoints.html` 也提及。

#### `WALLTIME` ⭐
- **类型**：string　**别名**：`WALLTI`
- **用法**：`WALLTIME {real}` 或 `WALLTIME {HH:MM:SS}`
- **官方描述**：Maximum execution time for this run. Time in seconds or in HH:MM:SS.
- **关联**：达到墙钟时间会**终止优化**（官方 geometry_and_cell_opt 明确列出终止条件之一）。

#### `PROGRAM_NAME`
- **类型**：enum　**默认**：`CP2K`　**别名**：`PROGRAM`
- **用法**：`PROGRAM_NAME {STRING}`
- **官方描述**：Which program should be run
- **可选值**：
  - `ATOM` — Runs single atom calculations
  - `FARMING` — Runs N independent jobs in a single run
  - `TEST` — Do some benchmarking and testing
  - `CP2K` — Runs one of the CP2K package
  - `OPTIMIZE_INPUT` — A tool to optimize parameters in a CP2K input
  - `OPTIMIZE_BASIS` — A tool to create a MOLOPT or ADMM basis for a given set of training structures
  - `TMC` — Runs Tree Monte Carlo algorithm using additional input file(s)
  - `MC_ANALYSIS` — Runs (Tree) Monte Carlo trajectory file analysis
  - `SWARM` — Runs swarm based calculation

#### `SEED`
- **类型**：integer[]　**默认**：`2000`
- **用法**：`SEED {INTEGER} .. {INTEGER}`
- **官方描述**：Initial seed for the global (pseudo)random number generator to create a stream of normally Gaussian distributed random numbers. **Exactly 1 or 6 positive integer values are expected.** A single value is replicated to fill up the full seed array with 6 numbers.

#### `OUTPUT_FILE_NAME`
- **类型**：string
- **用法**：`OUTPUT_FILE_NAME {filename}`
- **官方描述**：Name of the output file. **Relevant only if automatically started (through farming for example).** If empty uses the project name as basis for it.

### 2.2 诊断与调试

#### `ECHO_INPUT`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **用法**：`ECHO_INPUT NO`
- **官方描述**：If the input should be echoed to the output **with all the defaults made explicit**
- **用途**：想确认"我的输入里没写的关键字实际取了什么默认值"时，开这个最直接。

#### `ECHO_ALL_HOSTS`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **用法**：`ECHO_ALL_HOSTS NO`
- **官方描述**：Echo a list of hostname and pid for all MPI processes.

#### `CALLGRAPH`
- **类型**：enum　**默认**：`NONE`　**Lone keyword**：`MASTER`
- **用法**：`CALLGRAPH {NONE|MASTER|ALL}`
- **官方描述**：At the end of the run write a callgraph to file, which contains detailed timing informations. This callgraph can be viewed e.g. with the open-source program kcachegrind.
- **可选值**：
  - `NONE` — No callgraph gets written
  - `MASTER` — Only the master process writes his callgraph
  - `ALL` — All processes write their callgraph (into a separate files).

#### `CALLGRAPH_FILE_NAME`
- **类型**：string
- **用法**：`CALLGRAPH_FILE_NAME {filename}`
- **官方描述**：Name of the callgraph file, which is written at the end of the run. If not specified the project name will be used as filename.

#### `TRACE`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **官方描述**：If a debug trace of the execution of the program should be written

#### `TRACE_MASTER`
- **类型**：logical　**默认**：`T`　**Lone keyword**：`T`
- **官方描述**：For parallel TRACEd runs: only the master node writes output.

#### `TRACE_MAX`
- **类型**：integer　**默认**：`2147483647`
- **用法**：`TRACE_MAX 100`
- **官方描述**：Limit the total number a given subroutine is printed in the trace. Accounting is not influenced.

#### `TRACE_ROUTINES`
- **类型**：string[]
- **用法**：`TRACE_ROUTINES {routine_name1} {routine_name2} …`
- **官方描述**：A list of routines to trace. If left empty all routines are traced. Accounting is not influenced.

#### `FLUSH_SHOULD_FLUSH`
- **类型**：logical　**默认**：`T`　**Lone keyword**：`T`
- **官方描述**：Flush output regularly, enabling this option might degrade performance significantly on certain machines.
- **实用提示**：在共享文件系统上跑长任务时，保持 `T` 能让输出实时可见（代价是可能的性能下降）。

#### `EPS_CHECK_DIAG`
- **类型**：real　**默认**：`-1.00000000E+000`
- **用法**：`EPS_CHECK_DIAG 1.0E-14`
- **官方描述**：Check that the orthonormality of the eigenvectors after a diagonalization fulfills the specified numerical accuracy. **A negative threshold value disables the check.**

#### `SAVE_MEM`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **官方描述**：Some sections of the input structure are deallocated when not needed, and reallocated only when used. This reduces the required maximum memory.

#### `ENABLE_MPI_IO`
- **类型**：logical　**默认**：`T`　**Lone keyword**：`T`
- **用法**：`ENABLE_MPI_IO FALSE`
- **官方描述**：Enable MPI parallelization for all supported I/O routines. Currently, only cube file writer/reader routines use MPI I/O. **Disabling this flag might speed up calculations dominated by I/O.**

### 2.3 并行与数学库选择

#### `PREFERRED_DIAG_LIBRARY` ⭐
- **类型**：enum　**默认**：`ELPA`
- **用法**：`PREFERRED_DIAG_LIBRARY ELPA`
- **官方描述**：Specifies the diagonalization library to be used. **If not available, the ScaLAPACK library is used.** Complex (k-point) matrices use ELPA only when it is requested explicitly
- **可选值**：
  - `ELPA` — ELPA library
  - `SCALAPACK` — ScaLAPACK library
  - `SL` — ScaLAPACK library (shorthand)
  - `CUSOLVER` — cuSOLVER (CUDA GPU library)
  - `DLAF` — DLA-Future (CUDA/HIP GPU library)
- **故障排查关联**：官方 troubleshooting 提到可用 `PREFERRED_DIAG_LIBRARY SCALAPACK` 绕过 ELPA 的 bug #4484。

#### `PREFERRED_FFT_LIBRARY`
- **类型**：enum　**默认**：`FFTW3`
- **用法**：`PREFERRED_FFT_LIBRARY FFTW3`
- **官方描述**：Specifies the FFT library which should be preferred. If it is not available, use FFTW3 if this is linked in, if FFTW3 is not available use FFTSG. Improved performance with FFTW3 can be obtained specifying a proper value for FFTW_PLAN_TYPE. **Contrary to earlier CP2K versions, all libraries will result in the same grids**, i.e. the subset of grids which all FFT libraries can transform. FFTW3 is often (close to) optimal, and well tested with CP2K.
- **可选值**：
  - `FFTSG` — Stefan Goedecker's FFT (FFTSG), always available, will be used in case a FFT library is specified and not available.
  - `FFTW3` — a fast portable FFT library. **Recommended.** See also `FFTW_PLAN_TYPE` and `FFTW_WISDOM_FILE_NAME`.
  - `FFTW` — Same as FFTW3 (for compatibility with CP2K 2.3)

#### `FFTW_PLAN_TYPE`
- **类型**：enum　**默认**：`ESTIMATE`
- **用法**：`FFTW_PLAN_TYPE PATIENT`
- **官方描述**：FFTW can have improved performance if it is allowed to plan with explicit measurements which strategy is best for a given FFT. While a plan based on measurements is generally faster, **differences in machine load will lead to different plans for the same input file, and thus numerics for the FFTs will be slightly different from run to run.** **PATIENT planning is recommended for long ab initio MD runs.**
- **可选值**：
  - `ESTIMATE` — Quick estimate, no runtime measurements.
  - `MEASURE` — Quick measurement, somewhat faster FFTs.
  - `PATIENT` — Measurements trying a wider range of possibilities.
  - `EXHAUSTIVE` — Measurements trying all possibilities - use with caution.

#### `FFTW_WISDOM_FILE_NAME`
- **类型**：string　**默认**：`/etc/fftw/wisdom`
- **用法**：`FFTW_WISDOM_FILE_NAME wisdom.dat`
- **官方描述**：The name of the file that contains wisdom (pre-planned FFTs) for use with FFTW3. Using wisdom can significantly speed up the FFTs. **Note that wisdom is not transferable between different computer (architectures).** Wisdom can be generated using the `fftw-wisdom` tool that is part of the fftw installation. `cp2k/tools/cp2k-wisdom` is a script that contains some additional info, and can help to generate a useful default for `/etc/fftw/wisdom` or particular values for a given simulation.

#### `FFT_POOL_SCRATCH_LIMIT`
- **类型**：integer　**默认**：`15`
- **官方描述**：Limits the memory usage of the FFT scratch pool, potentially reducing efficiency a bit

#### `PREFERRED_DGEMM_LIBRARY`
- **类型**：enum　**默认**：`BLAS`
- **用法**：`PREFERRED_DGEMM_LIBRARY SPLA`
- **官方描述**：Specifies the DGEMM library to be used. If not available, the BLAS routine is used. This keyword affects some DGEMM calls in the WFC code and turns on their acceleration with SpLA. **This keyword affects only local DGEMM calls, not the calls to PDGEMM** (see keyword `FM%TYPE_OF_MATRIX_MULTIPLICATION`).
- **可选值**：`SPLA` — SPLA library；`BLAS` — BLAS library

#### `PREFERRED_CHOLESKY_LIBRARY` ⭐
- **类型**：enum　**默认**：`SCALAPACK`
- **用法**：`PREFERRED_CHOLESKY_LIBRARY DLAF`
- **官方描述**：Specifies Cholesky decomposition library to be used. If not available, the ScaLAPACK library is used
- **可选值**：`SCALAPACK`；`SL` — ScaLAPACK library (shorthand)；`DLAF` — DLA-Future (CUDA/HIP GPU library)

#### `DIRECT_GENERALIZED_DIAGONALIZATION`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **官方描述**：Request direct generalized eigenvalue problem diagonalization without a CP2K-side Cholesky reduction in supported dense matrix paths. **The eigensolver is still selected by `PREFERRED_DIAG_LIBRARY`.**

#### `BLACS_GRID`
- **类型**：enum　**默认**：`SQUARE`
- **用法**：`BLACS_GRID SQUARE`
- **官方描述**：how to distribute the processors on the 2d grid needed by BLACS (and thus SCALAPACK)
- **可选值**：
  - `SQUARE` — Distribution by matrix blocks
  - `ROW` — Distribution by matrix rows
  - `COLUMN` — Distribution by matrix columns

#### `BLACS_REPEATABLE`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **官方描述**：Use a topology for BLACS collectives that is guaranteed to be repeatable on homogeneous architectures

#### `ALLTOALL_SGL`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **用法**：`ALLTOALL_SGL YES`
- **官方描述**：All-to-all communication (FFT) should use single precision

### 2.4 ELPA 相关（5 个）

#### `ELPA_KERNEL`
- **类型**：enum　**默认**：`AUTO`
- **官方描述**：Specifies the kernel to be used when ELPA is in use for **real symmetric** matrices
- **可选值**：`AUTO`、`GENERIC`、`GENERIC_SIMPLE`、`BGP`、`BGQ`、`SSE`、`SSE_BLOCK2`、`SSE_BLOCK4`、`SSE_BLOCK6`、`AVX_BLOCK2`、`AVX_BLOCK4`、`AVX_BLOCK6`、`AVX2_BLOCK2`、`AVX2_BLOCK4`、`AVX2_BLOCK6`、`AVX512_BLOCK2`、`AVX512_BLOCK4`、`AVX512_BLOCK6`、`NVIDIA_GPU`、`AMD_GPU`、`INTEL_GPU`

#### `ELPA_COMPLEX_KERNEL`
- **类型**：enum　**默认**：`AUTO`
- **官方描述**：Specifies the kernel to be used when ELPA is in use for **complex Hermitian** matrices (k-points)
- **可选值**：`AUTO`、`GENERIC`、`GENERIC_SIMPLE`、`BGP`、`BGQ`、`SSE_BLOCK1`、`SSE_BLOCK2`、`AVX_BLOCK1`、`AVX_BLOCK2`、`AVX2_BLOCK1`、`AVX2_BLOCK2`、`AVX512_BLOCK1`、`AVX512_BLOCK2`、`NVIDIA_GPU`、`AMD_GPU`、`INTEL_GPU`

#### `ELPA_NEIGVEC_MIN`
- **类型**：integer　**默认**：`64`
- **用法**：`ELPA_NEIGVEC_MIN 32`
- **官方描述**：Minimum number of eigenvectors for the use of the eigensolver from the ELPA library. **The eigensolver from the ScaLAPACK library is used as fallback for all smaller cases**

#### `ELPA_ONE_STAGE`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **官方描述**：For ELPA, enable the one-stage solver (instead of the two-stage solver). **Please note, `ELPA_QR` and `ELPA_KERNEL` settings may be ignored.**

#### `ELPA_QR`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **官方描述**：For ELPA, enable a blocked QR step when reducing the input matrix to banded form before diagonalization. Requires ELPA version 201505 or newer and is automatically deactivated otherwise. QR is activated only when the matrix size is suitable. Keyword `ELPA_PRINT` helps identify suitable cases. Can accelerate diagonalization for suitable matrices.

#### `ELPA_PRINT`
- **类型**：logical　**默认**：`F`　**Lone keyword**：`T`
- **官方描述**：Controls the printing of ELPA diagonalization information. Useful for testing purposes, especially together with keyword `ELPA_QR`.

### 4.11 单位书写语法（官方静态计算教程）

CP2K 中可用**方括号包裹单位**（如 `[K]`）置于数值前，显式定义输入值的单位：

```
&SMEAR ON
  METHOD FERMI_DIRAC
  ELECTRONIC_TEMPERATURE [K] 300
&END SMEAR
```

## 5. 官方静态计算完整示例（Si bulk8）

> 来源：<https://www.cp2k.org/howto:static_calculation>
> 体系：面心立方（fcc）体相硅，8 个原子在立方晶胞中。官方示例用 CP2K 2.4 验证。

### 5.1 必需文件

| 文件名 | 说明 |
|---|---|
| `Si_bulk8.inp` | 主输入文件（**用户必须自行编写**） |
| `BASIS_SET` | 基组参数 |
| `GTH_POTENTIALS` | 赝势参数 |

官方说明：基组与赝势文件列表可在 `cp2k/data/` 目录中找到；主输入文件名可任意，扩展名也可任意。

### 5.2 完整输入（原文）

```
&GLOBAL
  PROJECT Si_bulk8
  RUN_TYPE ENERGY_FORCE
  PRINT_LEVEL LOW
&END GLOBAL
&FORCE_EVAL
  METHOD Quickstep
  &SUBSYS
    &KIND Si
      ELEMENT   Si
      BASIS_SET DZVP-GTH-PADE
      POTENTIAL GTH-PADE-q4
    &END KIND
    &CELL
      A     5.430697500    0.000000000    0.000000000
      B     0.000000000    5.430697500    0.000000000
      C     0.000000000    0.000000000    5.430697500
    &END CELL
    &COORD
      Si    0.000000000    0.000000000    0.000000000
      Si    0.000000000    2.715348700    2.715348700
      Si    2.715348700    2.715348700    0.000000000
      Si    2.715348700    0.000000000    2.715348700
      Si    4.073023100    1.357674400    4.073023100
      Si    1.357674400    1.357674400    1.357674400
      Si    1.357674400    4.073023100    4.073023100
      Si    4.073023100    4.073023100    1.357674400
    &END COORD
  &END SUBSYS
  &DFT
    BASIS_SET_FILE_NAME  BASIS_SET
    POTENTIAL_FILE_NAME  GTH_POTENTIALS
    &QS
      EPS_DEFAULT 1.0E-10
    &END QS
    &MGRID
      NGRIDS 4
      CUTOFF 300
      REL_CUTOFF 60
    &END MGRID
    &XC
      &XC_FUNCTIONAL PADE
      &END XC_FUNCTIONAL
    &END XC
    &SCF
      SCF_GUESS ATOMIC
      EPS_SCF 1.0E-7
      MAX_SCF 300
      &DIAGONALIZATION  ON
        ALGORITHM STANDARD
      &END DIAGONALIZATION
      &MIXING  T
        METHOD BROYDEN_MIXING
        ALPHA 0.4
        NBROYDEN 8
      &END MIXING
    &END SCF
  &END DFT
  &PRINT
    &FORCES ON
    &END FORCES
  &END PRINT
&END FORCE_EVAL
```

### 5.3 官方对每个关键字的说明（要点）

**`&GLOBAL`**

| 关键字 | 官方说明 |
|---|---|
| `RUN_TYPE ENERGY_FORCE` | 静态能量与力计算必须设为 `ENERGY_FORCE` |
| `PROJECT` | 是 `PROJECT_NAME` 的**别名**；CP2K 自动生成的所有输出文件都以它为前缀 |
| `PRINT_LEVEL LOW` | 控制主输出默认详细程度；可在各子段中覆盖 |

**`FORCE_EVAL` / `METHOD`**

- `METHOD Quickstep` 选择原子受力评估方法为 QUICKSTEP，即使用**高斯与平面波（GPW）**方法的 DFT。

**`&SUBSYS`**

- 每个元素**必须有一个** `KIND` 子段。
- `BASIS_SET` 与 `POTENTIAL` 的名称**必须**对应 `FORCE_EVAL/DFT` 中 `BASIS_SET_FILE_NAME` 与 `POTENTIAL_FILE_NAME` 指定文件里**已有的条目**。
- `&CELL`：`A`、`B`、`C` 分别是第一、第二、第三晶格向量；**Angstrom（埃）是默认单位**。
- `&COORD`：默认格式 `<ATOM_KIND> X Y Z`，X/Y/Z 为**笛卡尔坐标，单位埃**。设置 `SCALED` 为 `.TRUE.` 可改用**分数坐标**；`UNIT` 关键字可改笛卡尔坐标单位。`<ATOM_KIND>` 标签必须对应 `KIND` 中定义的元素。

**`&DFT`**

- `BASIS_SET_FILE_NAME` / `POTENTIAL_FILE_NAME` 设置存放基组和赝势参数的文件。
- `&QS` 的 `EPS_DEFAULT` 设置 QUICKSTEP 内**所有容差的默认值**；各个单独容差（`EPS_*`）可单独设置并**覆盖** `EPS_DEFAULT`。
- `&MGRID`：QUICKSTEP 使用**多网格方法**在网格上数值表示高斯函数——**狭窄尖锐的高斯函数映射到更细的网格，宽而平滑的高斯函数映射到更粗的网格**。
  - `NGRIDS 4` — 设置 4 层多网格
  - `CUTOFF 300` — 最细网格的平面波截断 300 Ry
  - `REL_CUTOFF 60` — 任何高斯函数下方的网格间距应比等效平面波截断 60 Ry 更细
- `&XC`：定义交换-相关密度泛函；本例 `PADE` LDA，与所选基组和赝势一致。
- `&SCF`：

| 关键字 | 官方说明 |
|---|---|
| `SCF_GUESS ATOMIC` | 用原子电荷密度重叠生成初始密度。**正确的初始密度对快速收敛很重要** |
| `EPS_SCF 1.0E-7` | 电荷密度残差容差，**覆盖 `QS` 中设置的 `EPS_DEFAULT`** |
| `MAX_SCF 300` | 每次基态能量计算允许的最大自洽循环步数 |

- `&DIAGONALIZATION ON` + `ALGORITHM STANDARD`：用**传统对角化**找基态；`STANDARD` 表示用标准 **LAPACK/SCALAPACK** 子程序。
  - 替代方案是 **OT**：若采用 OT，应**删除** `DIAGONALIZATION` 块，或把 `ON` 改为 `OFF`，并添加 `OT` 子段。
- `&MIXING T`：`METHOD BROYDEN_MIXING`、`ALPHA 0.4`（0.4 份输出密度 + 0.6 份输入密度）、`NBROYDEN 8`（别名 `NBUFFER`，历史数目）。
  - **重要**：`MIXING` **仅适用于传统对角化方法**；OT 使用不同的电荷混合方式。
- `&PRINT/&FORCES ON`：在主输出中打印原子力。

### 5.4 运行命令（官方）

```
mpirun -n 2 cp2k.popt -o Si_bulk8.out Si_bulk8.inp &
```

- 前提：已编译可用的 CP2K，可执行文件路径在 `PATH` 中；三个文件位于同一工作目录。
- `-o` 把输出重定向到文件。
- **注意**：`-o` 会**追加**（append）连续多次运行的输出。**若想完全从头开始，必须在新计算前删除 `Si_bulk8.out`。**

### 5.5 输出文件（官方）

| 文件 | 说明 |
|---|---|
| `Si_bulk8.out` | 作业主输出 |
| `Si_bulk8-RESTART.wfn` | 计算得到的最终 Kohn-Sham 波函数 |
| `Si_bulk8-RESTART.wfn.bak-<n>` | 记录第 `<n>` 个先前 SCF 步获得的波函数 |

**从上次波函数重启**：把 `SCF` 子段的 `SCF_GUESS` 改为 `RESTART`；前提是新计算与生成该波函数的计算**共享相同的 `PROJECT_NAME`**，否则需重命名重启波函数文件。

### 5.6 官方给出的结果检查要点

1. **SCF 迭代输出**：示例用对角化 + Broyden 混合，10 步收敛。
2. **能量与力**：应**始终检查**由最终电子密度算出的总电子数是否正确（本例 31.9999999939 ≈ 32）。
3. **力趋零的含义**：原子力接近零，**意味着体系基本弛豫，几何接近其基态最优结构**。

### 5.7 官方关于 smearing 的说明（金属/小带隙必需）

前述示例未对电子占据使用任何 smearing，**对大带隙体系这没问题**。但对**金属**或**小带隙体系**，可能因电子占据函数的不连续性导致计算不稳定、自洽循环永不收敛。

```
&SMEAR ON
  METHOD FERMI_DIRAC
  ELECTRONIC_TEMPERATURE [K] 300
&END SMEAR
```

**此外**：由于 smearing 可能导致分子轨道被占据到导带，必须告诉 CP2K 纳入额外的空（未占据）分子轨道（否则为降成本会被省略）：

```
ADDED_MOS 10
```

**注意**：对于给定的基组，可生成的分子轨道数（哈密顿量本征向量数）有上限，理论上限应为计算中所生成哈密顿量的**秩（rank）**。

**带 smearing 的输出会多出熵项**：

```
Electronic entropic energy:                                  -0.00001687947145
Fermi energy:                                                 0.20867150262130
```

- 熵项应**很小**，以便计算可靠地近似零电子温度结果。
- **最终自由能 = 总 DFT 能量 + 熵能**。
- **应该作为最终结果引用的是 TS→0 外推的自由能**。
